# Saber 能量光束

AK / Video Copilot Saber 风格的独立实现。0.7-local 在公共流程上扩充为 16 款自有预设，移除面板中间的公共参数提示。预设只设置同一组参数；光核／外围噪声独立，云纹、细丝、风和色彩过渡可直接组合。旧 0.1～0.5 PSD 继续保留原生成流程，可在界面明确转换。尚未发布。

新预设见 [0.7 本地说明](../docs/SABER_PRESETS_LOCAL.md)，公共参数、转换和保存格式 6 见 [0.6 说明](../docs/SABER_UNIFIED_LOCAL.md)；旧版专用控制见 [0.5 燃烧](../docs/SABER_BURNING_LOCAL.md)、[0.4 电流](../docs/SABER_ELECTRIC_LOCAL.md)和 [0.3 发光](../docs/SABER_GLOW_LOCAL.md)，输入与坐标限制见 [输入说明](../docs/SABER_LOCAL.md)。

从项目根目录执行 `./build.ps1 -Module energy`。构建不会安装到 Photoshop，也不会触碰其他插件二进制。
