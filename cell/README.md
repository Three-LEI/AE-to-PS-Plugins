# Cell Pattern 单元格图案 0.2

2026-11-05更新至0.2，随效果整包0.23提供。Windows x64原生Photoshop `.8bf`，菜单为“滤镜 → ZaYu-AE 效果复刻 → Cell Pattern 单元格图案”。独立C++实现，使用时无需AE。0.1及整包0.22保留为回退基线。

## 0.2性能更新

仅为特征点和最近邻查询添加一次渲染内的有界缓存，不共享跨线程或跨参数状态；约92KiB缓存由渲染结束统一释放。随机序列、公式、浮点运算顺序、采样和参数存储布局不变。既有九款插件及公共UI库保持不变。

管状固定输入CPU内核复测：256×192由92.78ms降至23.54ms（3.94倍），1024×768由1208.65ms降至333.79ms（3.62倍）。预热后分别取5/3次中位数，校验摘要不计时；这些数值不包含PS传输与显示，不等于整个预览窗口的加速倍数。气泡、晶格化等其它模式没有同等级收益。

96组浮点RGBA结果逐字节相同，37组AE参考渲染与0.1相同。新DLL额外与旧内核参考完成22,020,502项适配检查；PS默认气泡22份导出像素与旧版逐值相同。证据位于`../evidence/cell-v02/qa.json`与`parity.json`，旧版证据保留在`cell-v01`。

## 功能

气泡、晶体、印板、静态板、晶格化、枕状、晶体HQ、印板HQ、静态板HQ、晶格化HQ、混合晶体、管状，共12种模式。

- 默认对比度**100**、大小60、分散1、演化0、种子0，偏移为文档中心；200为增强对比参考组。
- 印板、静态板与晶格化系列显示“锐度”，禁用不适用的溢出选项。其它模式提供剪切、柔和限制、反绕。
- 两种晶格化读取当前目标图层的颜色和Alpha。纯色输入保留纯色，透明输入保留透明。
- 其它模式可在透明空层生成不透明灰度图案。AE气泡透明输入参考保持透明，因此空层生成为本PS版扩展行为。
- 支持反转、分散、大小、双坐标偏移、平铺单元数、演化、循环演化和种子；右键缩览图设置偏移。
- 共用数值拖动、主题、中英切换、DPI、关于、异步缩览图、背景、缩放和平移。
- 支持RGB8、PS16（32768白色标尺）及float32。最终图案范围为0–1，源图超出该范围的HDR颜色不予保留。

## AE对照与限制

使用已有AE26.5x89的37组512×320 PNG，以相同参数及相同保存的源图重新渲染。涵盖12模式的100/200两组及晶格化的彩色、渐变和透明输入。AE PNG按预乘RGB解释，内核使用直通RGBA。

管状改为稳定的互近邻线段图，避免逐像素切换最近点对造成截断，并校准管宽；混合晶体保留中灰周围的明暗变化。固定灰度参考的统计如下，标尺为0–255：

| 模式/对比度 | AE平均/标准差 | 本版平均/标准差 |
|---|---:|---:|
| 混合晶体100 | 131.68 / 14.07 | 130.82 / 13.81 |
| 混合晶体200 | 136.38 / 28.00 | 134.15 / 27.63 |
| 管状100 | 197.50 / 54.43 | 197.02 / 56.04 |
| 管状200 | 148.60 / 90.33 | 150.30 / 85.73 |

这些统计只描述固定参考的明暗分布。随机序列、拓扑、HQ内部算法、演化轨迹和细节均为独立建模，**相同种子不保证相同布局，不声称像素一致**。37组没有覆盖所有参数组合；平铺、循环和种子由自身性质测试验证，尚无对应AE参数扫描。HQ使用2×2子像素采样，不能等同于Adobe内部实现。

程序生成模式的平铺和指定循环具有自身周期一致性。晶格化几何可循环，源图采样不强制周期化，因此任意源图不保证无缝重复。

输出限于PS画布和滤镜作用范围。程序生成按512×64块输出；晶格化及保护透明度需在输出前冻结原始目标，源图上限16,777,216像素。晶格化预览源图最长边最多1024，边界颜色可能与原分辨率输出不同。只读取当前目标，不包含其它图层或图层蒙版。没有GPU、主画布实时预览或动作参数描述/智能滤镜参数重编辑；不自动解析ICC/ACES。

结果见`../evidence/cell-v02/qa.json`、`ae-comparison.json`和`host-pixels.json`，安装回执含源码/插件哈希及回退位置；旧九款与0.22整包相同。

## 构建与复现

先构建`native/build.ps1`，再运行`cell/build.ps1`；`-CoreOnly`只运行内核并构建参考渲染器。沿用主工程工具链路径。

```text
cell/build.ps1
python tests/compare_cell_reference.py --evidence-dir evidence/cell-v02
cell/build/dialog_preview.exe --qa-zh
cell/build/dialog_preview.exe --qa-en
cell/build/dialog_preview.exe --qa-zh-200
cell/build/dialog_preview.exe --qa-en-200
```

运行`tests/run_cell_cache_parity.ps1`生成新DLL对旧内核的参考检查。使用`tests/build_performance_probe.ps1`分别构建/运行旧内核和新内核，输出到`evidence/cell-v02/performance`，详见本轮任务记录。

宿主脚本`cell/tests/host_smoke.jsx`只创建临时文档并保留已有文档；运行后执行`python tests/verify_cell_host.py --evidence-dir evidence/cell-v02 --baseline-dir evidence/cell-v01`。`python tests/verify_cell_cache_release.py --preinstall`生成安装前检查，`tests/install_cell_cache_release.ps1`备份并安装；完成宿主复测后运行`python tests/verify_cell_cache_release.py`和`python tests/package_cell_cache_release.py`打包0.23。开发工具需要现有基线/AE参考及Pillow/NumPy，成品运行不需要这些工具。
