# Film Damage 胶片损伤

独立静态胶片损伤：颗粒、灰尘、毛发、污渍、断续划痕、褪色、暗角、漏光、失焦和固定状态抖动，八组自有预设。

本机 0.2 新增高光红晕、独立损伤分布和颗粒柔和度；旧预设与 PSD 使用原参数和画面。

本机 0.3 新增污渍纹理；0% 保持原污渍，调高后增加斑驳、断续沉积和浅色空隙。

本机 0.4 新增「污渍边缘粗糙度」；独立控制轮廓缺口和起伏，0% 保持 0.3 输出。

本机 0.5 新增「污渍边缘尺寸」；调小形成更细密的缺口，默认 100% 保持 0.4 输出。

使用公共缓存宿主、画布外坐标转换、自适应预览及完整参数保存。支持RGB8／16／32、HDR和源Alpha。算法由CPU确定性并行计算，不依赖AE或原版插件。

构建：项目根目录 `./build.ps1 -Module filmdamage`；纯核心 `./build.ps1 -Module filmdamage -CoreOnly`。Adobe SDK和工具链自行配置，见[构建说明](../docs/BUILDING.md)。[使用说明与限制](../docs/FILMDAMAGE_LOCAL.md)。当前仅本机 0.5，未包含在 0.38 正式包。
