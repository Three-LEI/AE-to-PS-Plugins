# Turbulent Displace 湍流置换 / Light Sweep 扫光 / Kaleida 万花筒 0.1

整包0.32新增第十六至十八款Photoshop原生滤镜，按湍流置换、扫光、万花筒顺序开发。菜单：**滤镜 → ZaYu-AE 效果复刻**。均支持RGB8/16/32、智能滤镜完整参数保存、单项蓝色重置、全部重置、中英／DPI、颜色取样、背景预览及缩放平移。使用无需AE、原版插件、外部贴图或刷新脚本。完整输入上限16,777,216像素。

## 湍流置换

内部噪声驱动形变，适合液态文字、水波、热扰动和纹理。保留9种类型：湍流、膨胀、扭转、三种平滑变体、垂直、水平及交叉置换；数量、大小、偏移、复杂度、演化、循环与种子。固定边缘约束边缘的法向位移，锁定边缘同时约束两个方向；包含无固定及7种固定、7种锁定组合。垂直／水平／交叉采用一维位移场，交叉组合前两者。

增加独立水平／垂直强度、透明／延伸／平铺／镜像边界、近邻／双线性／四点采样及效果混合。演化在PS中作为静态选形参数，没有时间线或关键帧。**Resize Layer固定关闭**，不能自动扩展PS图层或画布。

噪声为独立生成，使用AE同源参考校准位移强度、类型、方向、固定／锁定及循环语义；**同一种子、相同参数不保证生成AE相同的随机形状**，也不以随机场RGB逐像素误差作为通过依据。参考中的数量为0和半透明中性输入、完整演化循环、种子变化、限定区域的位移标准差与方向约束有单独检查。若重视与既有AE图案完全相同，应继续使用该AE项目渲染。

## 扫光

独立重建CC Light Sweep的单层扫光：中心、方向、线性／平滑／锐利三种衰减、宽度、扫光强度、边缘强度／厚度、光照颜色和叠加／合成／剪出三种接收方式。适合文字、Logo、透明图形的高光与浮雕边缘。默认中心为文档横向中点、纵向四分之一，方向−30°、宽度50、强度25、边缘强度50、厚度4；颜色沿用AE的暖白。

叠加可保留HDR高光；合成为颜色覆盖；剪出以光带形成Alpha。只使用效果自身光照，不依赖PS灯光系统。边缘光照是独立近似，细小轮廓、高强度与原版仍可能有差异。

## 万花筒

独立重建CC Kaleida的9种镜像：Unfold、Wheel、Fish Head、Can Meas、Flip Flop、Flower、Dia Cross、Flipper和Starlish，包含中心、大小、旋转和浮动中心。默认Flower，大小20%，中心为文档中心。可用于装饰纹样、几何背景和纹理生成；输入应在中心附近有图像内容。

镜像以平铺方格、转置、三角折叠和角度折叠构造。大小与文档宽度关联，旋转作用于源采样区域；开启浮动中心时，输出图案中心跟随中心参数。另提供与湍流相同的边界、采样质量和混合控制。抗锯齿与极端参数的细节仍可能不同。

## 使用与验证

右键预览可设置中心／偏移。单项箭头只重置对应参数；“全部重置”恢复文档默认值。完整分辨率结果在CPU后台计算，预览缩放和平移不改变输出。高质量四点采样、较高复杂度会增加计算时间。

智能滤镜逐字段保存参数，保存PSD并重启PS后可恢复；修改智能对象自身内容时会按保存参数重算。三款均无外部参考层，不存在跨层依赖刷新。不会重新安装已移除的参考层脚本。背景层与锁定Alpha遵守PS宿主限制。

验证入口：`evidence/creative-v01/qa.json`、`ae-parity.json`及`任务记录.md`。AE 26.5x89的81组自制8位同源参考包括菜单序号／分隔项、固定与锁定、种子与演化、扫光衰减／颜色／Alpha和9种平铺镜像。已单独验证AE的saveFrameToPng输出RGB为预乘值，比较时按预乘空间处理，避免透明边缘被重复乘Alpha。

误差阈值与实测指标只适用于记录的参考，不代表所有照片和文字逐像素一致。AE图像对照采用8位，PS的RGB8/16/32另行验证。纯数学／实际DLL测试覆盖HDR、Alpha、分块、保护Alpha、取消、错误清理及24组串行／并行逐字节一致；生产UI覆盖三款中英和100%／200%。PS实机覆盖普通滤镜和多实例智能滤镜的保存／重启恢复、源内容变化与画布外移动。

构建：`creative/build.ps1`，可加`-CoreOnly`。沿用工程LLVM-MinGW、Adobe官方SDK、Dear ImGui及现有`native/build`静态库。旧十五款DLL、已有原生源码与共享UI库均保持0.31原样。整包：`dist/ZaYu-AE-Effects-0.32.zip`；开发包：`dist/AEPS-Common-0.32.zip`。开发包示例保留主工程相对目录和SDK／工具链假设，不是独立的免依赖构建。
