# Compound Blur 复合模糊 0.1.1

在「滤镜 → ZaYu-模糊和锐化」打开。模糊图的黑色区域保持清晰，白色达到「最大半径」，中间灰度对应不同的模糊半径。「反相」交换两端的作用。「查看模糊图」在窗口里显示实际控制灰度，点确定时应用模糊效果。

- 「内置渐变」提供线性、径向、对称、角度和菱形。展开「渐变位置」可调中心、角度与跨度。中心和跨度以文档为基准，选区只限制输出范围。
- 渐变编辑器支持在色带上双击添加色标，也可用按钮添加、删除、复制和反转。色标可以拖动或精确输入位置，支持 2–16 个。每个色标可调灰度和不透明度，选中后可调整与下一色标之间的中点。插值有线性、平滑和阶梯，预设提供黑白渐变和两端对称的灰度分布。
- 「参考图层」可用当前图层或其他可读取的图层，包括隐藏图层。参考图按文档坐标对齐，可使用亮度或 Alpha。透明区域和图层外的值为黑色，反相后为白色。改动参考图层后，重新打开智能滤镜以刷新。保存后的来源按图层名称匹配。
- 效果以可见颜色加权采样，保留原图透明度。0.1.1 对粗尺度先做预滤波，再用三次 B 样条重建，修正较大半径时可见的方格。预览和应用共享这一采样方法，预览期间可复用已计算的尺度。

渐变的色标和几何计算独立于 Photoshop，在 `native/common/gradient.hpp` 中提供。`native/ui/include/psui/gradient_editor.hpp` 提供公共面板，支持 RGBA 和灰度模式。空间渐变可单独调用渐变类型和位置控件。色标、插值、几何、来源与模糊参数随智能滤镜保存。

从工作区根目录运行 `./build.ps1 -Module compoundblur`。 [参数窗口](../docs/GALLERY.md#compound-blur) · [Adobe Compound Blur](https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/blur-sharpen-effects.html)
