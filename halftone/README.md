# Halftone 网点印刷（0.38收录）

**已收录0.38正式版。** 内部组件编号沿用开发编号，发行渠道以整包版本为准。[安装包](https://github.com/Three-LEI/AE-to-PS-Plugins/releases/download/v0.38/AE-to-PS-Plugins-0.38-Windows-x64.zip) · [验证范围](../docs/VALIDATION.md)

把照片、文字和透明图层转换成可调整的单色／双色半调网纹。已纳入0.38正式版。

## 参数

- 圆点、方点、菱形、线条；暗色网点与亮色网点。
- 间距 2–1000 像素、角度、宽高比、边缘柔化、二维网纹偏移。间距越小，网点越密。
- 源平滑、明亮度、对比度和伽马，分别调整细节与明暗分布。
- 暗色与亮色、纸色／透明背景、效果混合。
- 六组预设：标准、漫画、复古双色、冷色亮点、斜线印刷、透明油墨。预设只设置上述公共参数。

使用纸色背景时保留源 Alpha；透明背景按网点覆盖率减少 Alpha，适合在下方放置纸张或其他底图。背景层和锁定透明度会限制透明输出，建议普通透明图层或智能对象。缩小查看很细的网点时会趋近平均色，放大到 100% 可检查实际形状。

支持 RGB8／16／32、中文／English、蓝色单项重置／全部重置、拖动时快速预览和停止后精细补全。智能滤镜保存全部 20 个字段及实例身份；普通像素层直接应用保留栅格结果。

## 算法与范围

参考 [Sapphire HalfTone 的公开参数](https://borisfx.com/documentation/sapphire/ae/halftone/)，以独立的网格面积阈值、像素采样和 Alpha 加权源平滑实现。圆点从独立墨点逐渐连接，并在深色区域留下纸色孔洞；参数尺度、内核和原版不保证逐像素一致。当前为单色／双色半调，CMYK 多色分版留待后续。

完整处理上限为 16,777,216 像素。亮度映射使用源 RGB 数值的 0–1 范围；混合为 0 时原样返回源图，包括 HDR 数值。图案使用文档坐标锚定，选区仅限制滤镜输出范围。

## 本机构建与测试

在项目根目录执行 `./build.ps1 -Module halftone`，输出 `halftone/build/ZaYuHalftone.8bf`。支持 `-CoreOnly`，沿用 MSVCRT 工具链、传统 PiPL/aete 和现有共享界面。

本地测试、参数窗口示例及安装信息见 [本地记录](../docs/HALFTONE_LOCAL.md)。旧 23 款滤镜不因构建本模块而重新生成。项目代码采用根目录 MIT 许可；第三方库许可保持。
