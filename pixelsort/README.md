# Pixel Sort 像素排序 0.1

在「滤镜 → ZaYu-风格化」打开。滤镜沿水平或垂直方向，将连续的合格像素按亮度排序，形成方向明确的条带。适合在照片或海报的局部制作故障纹理。

- 「亮度下限」与「亮度上限」决定哪些像素能进入条带。亮度范围外的像素和全透明像素会断开条带。
- 「排序顺序」可选暗到亮或亮到暗，水平从左到右，垂直从上到下。「最大条带长度」以文档像素计，较短的长度会将连续区域分成更细的条带。
- 用「效果混合」调节故障感。支持选区和智能滤镜，保留原图透明度。原尺寸可见区按完整行列计算条带，再裁出预览区域。

从工作区根目录运行 `./build.ps1 -Module pixelsort`。 [参数窗口](../docs/GALLERY.md#pixel-sort) · [Boris FX PixelSort](https://borisfx.com/documentation/sapphire/ae/pixelsort/)
