# Fractal Noise 分形杂色 0.2

独立 C++ x64 Photoshop 滤镜，不依赖 AE、额外 DLL 或开发工具。统一菜单为 **滤镜 → AE 效果复刻 → Fractal Noise 分形杂色**。Tint 色调 也在这个组。

本版将基础原型扩展为完整的参数面板，支持 RGB 8/16/32 位。各分形模型仍是独立近似，尚未与 Adobe AE 逐像素校准，尤其是动态、旋涡、绳状等复杂类型，不能承诺与 AE 相同参数得到相同纹理。

## 参数

| 分组 | 内容 |
| --- | --- |
| 基本 | 17 种分形模型；块、线性、柔和线性、样条 4 种插值；反转、对比度、亮度；剪切、柔和限制、折回、允许 HDR；1–20 的分数复杂度 |
| 变换 | 旋转；统一缩放或独立宽高；XY 偏移；透视位移 |
| 子设置 | 子影响、子缩放、子旋转、XY 子位移、中心辅助比例 |
| 演化选项 | 演化角度（360° 为一圈）、循环演化、循环圈数、32 位无符号随机种子 |
| 合成 | 不透明度和 29 种 RGB 混合模式，包含 AE 特有的将杂色映射为色相/饱和度的行为 |

分形模型：Basic、Turbulent Smooth / Basic / Sharp、Dynamic / Progressive / Twist、Max、Smeary、Swirly、Rocky、Cloudy、Terrain、Subscale、Small Bumps、Strings、Threads。共享值噪声基础，配合逐层域变形和非线性映射；不是 Adobe 内部算法。子旋转、缩放和位移按层累积；中心辅助比例通过共享格点种子构建对齐，透视位移通过层深度改变偏移，均属于近似建模。

数字框支持键盘输入更宽范围；滑块提供常用范围（例如缩放 1–600，输入可达 10000）。超出滑块范围的有效输入会保留，滑块停在端点。种子和循环圈数必须为整数。

## 窗口

分组标题上的三角用于展开/折叠二级参数；右侧自绘滚动条支持拖动、点击翻页和滚轮。Tab 进入数值框或滑块时自动滚动到该控件。窗口可调整大小，左侧预览、确认/取消/重置按钮固定。统一缩放与循环演化会自动启用对应字段。

预览保持窗口内缩略图逻辑，参数改变后合并更新；取消“预览”显示原图。确定后才处理文档，取消不应用效果。主题、折叠标题、滚动条、下拉框、滑块等来自共用 PSUI，避免白色系统箭头/滚动槽和虚线焦点框。重置恢复默认参数及文档中心偏移。

## 数据与边界

- 8 位按 255、PS 16 位按 32768 归一化；32 位 float 的 HDR 模式保留负数及大于 1 的结果。整型输出最终裁剪。
- 保留原图透明度；选择区由 PS 宿主管理。请在有像素的图层上运行，不能在透明空白区域生成不透明像素。
- “无 / None”在 RGB 输出中以黑色为底应用噪声不透明度，不混入原图；不生成 AE 式新的透明度。不提供模板 Alpha、轮廓 Alpha 等修改透明度的混合模式。
- 16/32 位原图会先归一化为 8 位缩略图，故预览不能精确呈现 HDR 源数据与混合的全部细节；最终处理使用原始位深。
- PS 中演化选择静态时刻，未提供时间轴动画。循环开关打开后，演化相隔“圈数 × 360°”会返回相同状态，一圈也会产生连续变化。
- 0.1 的参数句柄可升级，保留原数值和旧版剪切溢出行为；基础默认样张与 0.1 逐字节一致。稳定版备份为 `backups/v0.1/`。

参数语义参考 [Adobe 官方说明](https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/noise-grain-effects.html)。
