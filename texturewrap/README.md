# Sphere 球面贴图 0.5 与 Cylinder 圆柱贴图 0.6

在「滤镜 → ZaYu-透视」打开任一滤镜。「贴图 → 贴图来源」默认选「当前图层」，也可选择文档中的其他可读取图层，包含隐藏图层。滤镜按各自有像素的外接矩形取样，内部透明区和画布外的纹理也参与计算。结果应用到当前图层。

选中其他图层后会显示「保留当前层效果」。默认关闭，只用所选图层生成贴图。开启后，当前层先映射到完整球面或圆柱侧壁作为底材，外部贴图再按自身透明度覆盖同一曲面。局部贴花和包裹角度限定外部贴图的范围，透明处和范围以外可看到底材。

- **球面贴图**默认把纹理包到整球。用于经纬纹理时通常采用 2∶1 宽高比。勾选「贴图 → 局部贴花」，可以调整贴花经度、纬度和尺寸。贴花尺寸是长边的张角，图案在曲面中心的切平面上按源图宽高比缩放。来源为「当前图层」时，开启「局部贴花」也会显示「保留当前层效果」。勾选后，同一图层用于完整球面和局部贴花，两个映射按贴花透明度合成。当前图层和外部来源各自保存开关状态，默认关闭。
- **圆柱贴图**选择「当前图层」时也可勾选「保留当前层效果」。同一张图先铺满圆柱侧壁，再叠上可单独定位的贴花。包裹角度决定弧段宽度，周向位置沿圆周移动贴花，0° 是圆柱自己的正前方。上下位置按圆柱轴线定位贴花中心，0% 在顶端、50% 居中、100% 在底端。贴花高度以柱体高度为基准，滑出柱口的部分沿边缘裁切。「旋转」调整整个圆柱，「渲染面」可选仅正面、仅背面或正反面。当前图层与外部来源分别记住开关状态，默认关闭。

智能滤镜保存贴花位置和「保留当前层效果」的状态，按图层名称保存外部来源。旧 PSD 缺少这些字段时使用当前图层、关闭叠加以及默认的圆柱贴花位置（周向 0°、上下 50%、高度 100%）。若来源改名、被删除或出现重名，可重新打开滤镜选择。编辑来源图层后，重新进入滤镜并确定即可刷新。

中心 X、Y 按文档宽高的百分比定位。半径按文档短边的百分比计算，圆柱高度按文档高度的百分比计算。旋转依次应用 X、Y、Z 轴。光照支持方向、仰角、环境光、主光强度和高光。关闭「启用光照」可保留贴图原色，便于与样机原有的光影合成。

普通可写透明度图层在表面以外输出透明像素。背景层只能接收 RGB，透明区域在其上按黑色输出。效果受 Photoshop 的图层输出范围和选区约束。转换为智能对象后应用，可随 PSD 保存并再次编辑参数。

两款均支持 Windows x64、RGB 8／16／32 位和公共自适应预览。可用滚轮或缩放输入框放大，100% 及以上按原尺寸计算可见区。小幅平移复用已算好的像素，移出已有区域时维持上一帧效果，直到新区域算完。CPU 负责效果计算，显示使用现有的 WARP 软件兜底。

从工作区根目录运行 `./build.ps1 -Module texturewrap` 可构建两款 .8bf。单独检查渲染核心可加 `-CoreOnly`。演示见[球面贴图](../docs/GALLERY.md#sphere)和[圆柱贴图](../docs/GALLERY.md#cylinder)。

原版功能参考 [CycoreFX HD 手册](https://www.cycorefx.com/downloads/cfx_hd_std/CycoreFX%20HD%201.8.9%20Manual.pdf#page=50)。
