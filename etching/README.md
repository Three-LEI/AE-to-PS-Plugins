# Etching 蚀刻（0.38收录）

**已收录0.38正式版。** 内部组件编号沿用开发编号，发行渠道以整包版本为准。[安装包](https://github.com/Three-LEI/AE-to-PS-Plugins/releases/download/v0.38/AE-to-PS-Plugins-0.38-Windows-x64.zip) · [验证范围](../docs/VALIDATION.md)

参考 [Sapphire S_Etching公开参数](https://borisfx.com/documentation/sapphire/ae/etching/)，独立实现两组变粗细曲线、亮度扭曲与轮廓细节，生成货币雕版／蚀刻版画风格。工作区第28款效果／第21模块，已收录0.38。

支持双线蚀刻、单线版画、暗部交叉排线。可调两组频率与角度、位置、锐度、线宽、源平滑、波形和亮度扭曲、边缘强度／阈值／宽度／锐度，另有明暗／对比／伽马、墨色／纸色、保留源色、纸纹、透明墨线和效果混合。

六个自有公共参数预设：经典蚀刻、绿钞雕版、复古棕墨、单线肖像、交叉排线、蓝墨版画。它们设置同一套参数，选择预设保留线条偏移。默认参数尽量沿用公开参数的命名和主要默认值，图像内核独立实现，不承诺与商业原版逐像素相同。

公共快速预览、停止后精细补全、中英文、蓝色单项／全部重置、智能滤镜37字段保存。缩小计算仍保留原文档线网坐标，细于像素的线条按覆盖率融合；Fit显示对细线做面积平均，100%可观察线刻结构。最终完整计算。

支持RGB8／16／32。正常模式保留源Alpha，透明模式将纸色移除；背景层不能产生新的透明度，透明墨线建议普通图层或智能对象。使用PS选区／图层蒙版控制作用范围，不包含Mocha、外部遮罩输入或AE专用不透明度模式。

频率以画面短边归一化，增加得到更细密的线条。波形幅度、亮度扭曲和平滑也以短边归一化；源平滑和边缘宽度使用原文档像素。源平滑使用Alpha加权，防止透明区隐藏颜色污染图案。

项目根目录 `./build.ps1 -Module etching`；纯核心测试加 `-CoreOnly`。输出 `etching/build/ZaYuEtching.8bf`。使用及验证范围见[本地说明](../docs/ETCHING_LOCAL.md)。
