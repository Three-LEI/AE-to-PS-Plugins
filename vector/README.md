Vector Blur 矢量模糊 0.2
========================

独立的 Windows x64 Photoshop `.8bf` 滤镜，不需要安装或运行 After Effects。菜单位置：**滤镜 → ZaYu-AE 效果复刻 → Vector Blur 矢量模糊**。

建议先选择“流动”“轮廓流线”或“单向风”预设。默认“数量”为 0，打开时保持原图；可以直接输入像素距离，正负值在单向模式下反转拖尾。

0.2 同源 AE 校准
---------------

修正了 0.1 将自然模式当作双向平均模糊的问题。通过正常 AE 脚本和 PNG 输出，对照本机 After Effects 25.6.5x3 的 CC Vector Blur；两边导入同一张静态 PNG，再使用相同参数。未读取或移植原版代码。

本次校准包括后向坡度差分、带脊线 Z 分量的法线响应、自然模式单向累积、其它模式的采样权重，以及方向映射的中点/90°基准。映射柔化从“直接当作高斯 sigma”改为经实测标定的快速多次滑动盒式近似。

512×512 杂色、自然/数量50/角度0/脊线1/明度/柔化15，中央384×384区域的8位RGB平均绝对误差从旧版 **19.38/255** 降到 **1.00/255**。相同源图的五种模式分别约为1.00、0.44、0.60、0.60、0.52/255。21组检查还包含正负数量、25/100、柔化0/5/10/30、脊线0.5/2/5、90°角度与外部线性矢量图。这里是这组固定图像和参数的结果，不是任意图片的精度保证；边缘、小柔化和采样细节仍可能不同。

旧版保存参数自动升级，保留数量/角度/矢量图等值，关闭0.1默认开启的曲线流向。需要曲线效果时可重新启用；新参数仍兼容滤镜重复和存储句柄生命周期。

参考生成源文件：tests/ae_reference.jsx、make_ae_reference_inputs.py、ae_reference_more.jsx、ae_reference_directions.jsx。AE 命令行应从纯英文路径运行 JSX（原生命令行对本机中文脚本路径未可靠执行）；测试脚本只在空项目或确切的专用 reference.aep 中工作。参考工程和原版 PNG 保留在主工程 evidence/vector-ae-reference，插件运行不需要这些文件或 AE。

功能
----

- 五种类型：自然、恒定长度、垂直坡度、方向居中、方向衰减。坡度类按高度场法线调整矢量长度和脊线平滑度；方向类以通道中点为角度中心，并提供独立的旋转圈数。
- 矢量图直接使用当前图层或其他可读取的 PS RGB 图层，包括隐藏图层。无需另存 PSD。使用完整文档坐标，不因选区裁切改变映射中心。输入图层按唯一名称保存，丢失或重名会提示重新选择。
- 八种通道属性：红、绿、蓝、Alpha、亮度、明度、色相、饱和度。色相柔化使用圆周插值，避免红色色相两端被错误平均成青色。映射值限制在 0–1，源 HDR 色值独立保留。
- 可启用“沿曲线流向”，使用中点积分跟随连续的矢量场；关闭后使用局部直线采样。自然模式沿反向采样形成单向坡度拖尾，恒定长度/垂直坡度/方向居中均匀地向两侧采样，方向衰减单向渐隐。曲线流向默认关闭，以贴近 AE 基线；它仍可作为艺术化处理选项开启。
- 四档采样质量、效果混合、四种边缘处理、保留源透明度、可选线性光插值。线性选项使用手动近似的 2.2 伽马，不是完整 ICC 色彩管理。
- 缩览图可显示方向箭头；支持背景、滚轮锚点缩放、拖动平移、适合。箭头和背景只用于预览。背景仅显示当前图层及下方可见图层，沿用共享背景组件的近似范围。
- 复用主题、中英文实时切换、DPI、关于弹窗、ImGui 单一渲染表面及可取消异步预览；更新时保留上一帧完整画面。

范围和质量
----------

支持 RGB 8/16/32 位、透明图层和受保护透明度，PS 负责最终选区混合。使用预乘颜色和透明度采样，隐藏的透明 RGB 不贡献颜色。透明空层保持透明，矢量模糊不生成新内容。

模糊输出受 PS 画布和滤镜作用区域限制。完整原生 RGBA 快照沿用公共空间滤镜的 16,777,216 像素限制，较大文档会正常返回错误。大距离可提高质量；最高档最多约 257 个轨迹采样，极端长距离仍可能出现离散纹理。

CPU 采样最多使用 8 个工作线程。取消回调始终在发起渲染的线程执行，不在像素工作线程调用 PS API。开发机单次 1920×1080、标准质量、数量 80、曲线模式（含映射构建）约 1.21 秒，仅作本机参考。

原版公开参数语义参考 [Cycore 官方手册，第 9–10 页](https://www.cycorefx.com/downloads/cfx_hd_std/CycoreFX%20HD%201.7.1%20Manual.pdf)。本实现没有移植原版二进制或私有算法，强度、权重、流线轨迹与原版可能不同，不承诺像素一致。

构建与验证
----------

在主工程中先运行 `native/build.ps1` 生成共享静态库，再运行 `vector/build.ps1`。工具链为 LLVM-MinGW/C++20，使用官方 Photoshop C++ SDK 和 Dear ImGui 1.91.9b。UI 源码为 UTF-8/Unicode；仅宿主菜单 JSON 资源在构建时转换成 Windows 936 编码。

- 核心：五类型/八属性、外部矢量图、曲线/直线差异、色相环绕、正负数量、零值精确还原、HDR、Alpha、隐藏 RGB、边缘和取消。
- 实际 `.8bf` + 模拟宿主：RGB8/PS16/float32、非零模糊与隐藏图层输入、9 个不规则输出块、选区边界、16/32 位坐标、输入重名/缺失和错误清理。
- 生产面板：中文、英文、200% 缩放、滑块、预设、方向叠加、背景、缩放、关于、确认/取消及线程退出。
- 实际 PS：七款新菜单名称与分组，Vector Blur 的 RGB8/16/32 零数量默认值、撤销、选区、锁定 Alpha、空层和平面图。非零参数由实际 DLL 适配测试及生产面板测试覆盖，PS 脚本测试未交互调整非零参数。

证据：主工程 `evidence/vector-v02/vector-qa.json`、`vector-ae-parity.json`、`vector-ae-comparison.png`、`vector-modes.png`、`vector-flow.png`。已有六款仅更新名称/显示版本，滤镜算法与支持范围保持原样；其中 Tint 当前宿主适配仍只对 RGB8 启用。
