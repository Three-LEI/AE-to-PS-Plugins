# RepeTile 重复拼贴

以图层中有内容的区域为瓷砖，向上下左右扩展；对应 Cycore FX 的 CC RepeTile。支持 RGB8／16／32、智能滤镜参数保存、中英文和公共快速预览。

- 扩展按像素分别设置左、右、上、下。
- 拼贴模式：重复、水平翻转、垂直翻转、展开、180°翻转、随机、无、滑动、砖块。展开分别镜像两条轴；180°翻转只旋转棋盘格上交错的单元；滑动让隔列纵向错开半块，砖块让隔行横向错开半块。旋转拼贴等其余 Cycore 模式未收录。
- 接缝混合在瓷砖边缘做线性羽化；展开／无／滑动模式不启用。
- Photoshop 画布固定，只在滤镜所能写入的透明边距内填充。素材铺满画布时，先扩大画布并保留透明边距；用智能对象时，如果被对象边界裁切，可在智能对象源文件内留透明边距。
- 本机 0.2 的预览以同一张完整图层快照为输入。缩放和平移只改变看到的区域，交互预览降低分辨率时仍换算四向扩展和接缝的像素尺寸。

构建：`./build.ps1 -Module repetile`，可加 `-CoreOnly`。
