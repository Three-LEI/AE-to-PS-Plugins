# Toner 多色调

按亮度把图像映射到双色调、三色调、五色调或单色。对应 After Effects 的 Toner，独立实现，不调用 AE 或 Cycore 原版插件。

- 双色调：阴影、高光两种颜色。
- 三色调：阴影、中间调、高光，按 0%／50%／100% 亮度线性插值。
- 五色调：阴影、暗部、中间调、亮部、高光，按 0%／25%／50%／75%／100% 插值。
- 纯色：用“高光”颜色覆盖整个图层。
- 混合原图：0% 为纯效果，100% 为原图；与 AE 的方向一致。

支持 RGB8／16／32、智能滤镜参数保存、中英文、蓝色单项／全部重置和公共快速预览。

构建：在根目录运行 `./build.ps1 -Module toner`，可加 `-CoreOnly`。
