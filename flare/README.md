## 使用

在“滤镜 → ZaYu-AE 效果复刻 → Lens Flare 镜头耀斑”打开。用左键分别拖动预览中的光源和光学中心手柄，从空白处拖动可平移。光源可以移到画面外。

基础参数页八个自有预设：电影蓝光、暖阳、复古镜头、彩虹光环、宽银幕蓝、柔和自然光、洋红霓光、棱镜光圈。预设只设置同一套公共参数，不切换隐藏的生成算法；选择预设保留当前两点位置。设计器预设库另增加光弧晨曦、电影散景、星幕、光谱之翼，共十二个。

- 主要：光源／光学中心、整体亮度、尺寸、高宽比和颜色。
- 光源与光芒：热点、柔光、射线的独立亮度，射线数量、长度、粗细和旋转。
- 镜头鬼影：数量、3–16 叶片光圈、尺寸、间距、柔和和颜色。
- 光环与拉丝：彩色光环、光谱混色、横向拉丝的尺寸与亮度；旋转同时作用于射线和拉丝。
- 着色与气氛：伽马、饱和度、色相、静态气氛纹理和随机种子。
- 位置触发：光源经过边缘或光学中心附近时，按范围和倍率调节亮度。范围 0 关闭触发。
- 遮挡：当前层或外部参考层的 Alpha／亮度，反转、光源区域软采样。白色或不透明像素遮挡光源。
- 输出：滤色、相加、仅耀斑（透明），背景亮度、效果混合、保留源 Alpha。

透明模式输出直通 RGBA；相加模式的 RGB32 可保留超白发光值。混合 0 保留原图；默认输出会在可编辑透明区域生成光效。背景层会合成为不透明结果，锁定透明度会保留宿主 Alpha；透明输出建议普通图层或智能对象。滤镜不会自动扩展画布，请为光环预留边距。

外部参考层通过公共 Unicode 名称机制保存，重复同名或缺失时要求重新选择。修改外部层后需重新进入效果刷新，不创建自动刷新脚本。当前层遮挡会随该智能滤镜输入内容重算。

## 预览和兼容

沿用公共自适应预览：拖动时缩小计算，停止后自动完整计算；光源、光学中心与鬼影尺寸始终使用原生文档坐标。细热点、射线、拉丝和光环采用带能量补偿的采样宽度，减少缩小后的闪烁；快速帧仍是近似，最终输出完整计算。

支持 RGB8／16／32、中英文、蓝色单项／全部重置、智能滤镜原54字段及独立元素快照保存。最大完整输入 16,777,216 像素。沿用传统 PiPL/aete 与旧系统公共路径；本阶段新增传统 Unicode 文件选择及文件系统调用，Win7／CC2018 仍需外机复测。

这是静态二维重建，自有元素设计器与原版不保证功能或逐像素一致。不包含 Mocha 或 AE 三维灯光绑定；所有外观为自有预设，不读取原版预设或资源。

## 构建

项目根目录 `./build.ps1 -Module flare`；纯核心测试可加 `-CoreOnly`。输出 `flare/build/ZaYuLensFlare.8bf`。核心、真实 DLL、生产窗口和参数保存共用既有测试框架。验证及安装说明见 [本地说明](../docs/FLARE_DESIGNER_LOCAL.md)。
