## 界面与预览

- 紧凑布局：左侧缩略图，中间参数，右侧确定/取消/重置。窗口默认在 PS 中居中。
- 黑白映射、交换颜色、0–100% 着色量、点击色块调用 PS 原生颜色拾取器。
- 源码/资源使用 UTF-8，Win32 使用 Unicode 接口；中英双语标签适用于两种语言的 PS。
- 四档配色读取 PS 界面亮度，主题切换完整重绘背景和控件。
- 双缓冲自绘滑块，每帧完整覆盖背景，修复系统滑块拖动时的白色残影。
- 参数改变后约 25 ms 节流更新窗口内缩略图，连续拖动期间也更新；取消勾选“预览”显示原图。
- 预览只请求输入，不临时写主画布；确定后处理完整图像，取消不提交效果。

缩略图显示目标图层/选区区域，支持透明通道棋盘格及选区蒙版混合，不等同于含全部图层混合模式、调整图层的最终合成。宿主缺少缩略图接口时显示“无预览”并禁用开关；读取错误按 SDK 规则返回，不重复调用失败的宿主读取。

- `src/tint_dialog.cpp`、`src/tint.rc`：Tint 交互与布局。

- `build/dialog_preview.exe`：与正式插件共用界面的独立开发测试程序。

- `../evidence/native-ui-qa.json`：对应产物的实际界面与宿主验证记录。

共用库静态链接进 `.8bf`，用户无需额外 DLL 或开发工具。运行依赖只有 Windows 系统 DLL。

## 算法与边界

`L = 0.299 R + 0.587 G + 0.114 B`

`mapped = black + (white - black) L`

`output = input + amount (mapped - input)`

亮度系数、量化和色彩空间仍是待 AE 实测校准的复刻模型。HEX 解释为当前图像的数值 RGB。内核已有 PS16（白色 32768）和 float32，但 `.8bf` 尚未开放这些位深。智能滤镜参数保存见上方共用说明。

运行 `native/build.ps1`，仅内核用 `-CoreOnly`。脚本使用本机 LLVM-MinGW 工具链及 `../downloads/photoshop-cpp-sdk-main/pluginsdk`。构建不需要 AE、云账户或密钥。
