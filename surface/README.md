# Blobbylize 胶状化 / Glass 玻璃 0.2

0.2 / 整包 0.31：保留0.30加入的智能滤镜完整参数保存及画布外移动修复；按用户要求移除外部参考层刷新脚本。十五款插件二进制均与0.30相同。

外部参考层移动或修改文字／像素后，**不会自动触发这些智能滤镜重算**。需要更新时，双击智能滤镜中的 Glass／Blobbylize，打开窗口后会重新读取当前参考层；也可使用窗口内的“重新读取贴图”，最后点“确定”提交。没有外部刷新脚本、脚本菜单入口或后台监听器。

参考层按唯一名称关联。参考层改名、删除或出现重名时，打开效果重新选择，点“确定”后保存 PSD；不会自动追踪改名。旧0.30描述符中的辅助ID字段保留兼容。参考层必须是宿主可读取的普通像素／文本层；复杂分组与跨文档依赖未验证。

智能滤镜仍完整保存每个实例的数值、颜色、点光位置和参考层名称。保存 PSD 并重启 PS 后可恢复参数；修改智能对象自身内容会按原参数重新计算。生成内核和参数块结构不变。

旧 0.1 没有把完整参数写入智能滤镜描述符，已丢失的值无法恢复。旧 PSD 请核对并重新设置一次，用 0.2 确认后保存。此次持久化和刷新仅覆盖这两款，其它十三款保留原版本。

第十四、十五款 Photoshop 原生滤镜，独立重建 AE 的 CC Blobbylize 和 CC Glass。菜单位于 **滤镜 → ZaYu-AE 效果复刻**。两款支持 RGB8/16/32，完整源图上限 16,777,216 像素。使用无需 AE、Cycore 原版或外部渲染运行库。

- **Blobbylize 胶状化**：用当前或另一图层的通道生成柔和胶状轮廓、透明切除、折射和高光。默认柔和度 20、切除 25%、明度通道。
- **Glass 玻璃**：用凹凸贴图产生表面法线、折射位移和玻璃材质。默认柔和度 20、高度 25、置换 100、明度通道。

灯光固定使用 **效果灯光**。界面中没有“使用 AE 灯光”选项，保留效果内的远光、点光、强度、颜色、高度和方向／位置。远光启用方向，点光启用位置；点光模式还可右键预览定位。颜色使用共用 PS 拾色器与吸管。材质包含环境光、漫反射、镜面反射、粗糙度、金属。

| 参数 | 范围／行为 |
| --- | --- |
| 贴图 | 默认当前图层；可选 PS 图层的只读原生像素快照，不切换活动图层 |
| 属性 | 红、绿、蓝、Alpha、亮度、明度；亮度为加权 RGB，明度为最大／最小 RGB 的均值 |
| 柔和度 | 0–500，柔化高度场，继而改变轮廓和法线 |
| 切除 | 胶状化 0–100%；100% 输出空轮廓 |
| 高度／置换 | 玻璃高度 −100–100，置换 −500–500；高度负值翻转凹凸光照，折射按所测响应保留高度的二次关系 |
| 效果灯光 | 强度 0–1000%；远光／点光；高度 −100–100；颜色；点光位置或远光方向 |
| 材质 | 环境光 0–200%；漫反射、镜面反射、金属 0–100%；粗糙度 0.001–0.5 |

玻璃默认环境光／漫反射／镜面反射为 50/50/50；胶状化为 75/25/100。两款粗糙度均为 0.025，金属 100%，白色灯光强度 100%，高度 65、方向 −45°。点光位置按所测 AE 26.5 默认值设置：胶状化为文档四分之一位置，玻璃为文档中心，并计入文档坐标原点。

参数前的蓝色无边框箭头只重置对应项，底部“全部重置”恢复包括贴图、颜色、坐标和禁用项在内的全部效果参数。保留主题、中英切换、100%/200% DPI、数值拖动／输入、预览背景与缩放平移。预览使用完整源图异步计算并保留上一张完整结果；视图缩放不改变生成坐标或重新缩放贴图。CPU 按独立行并行，宿主读图与取消回调均在调用线程。

透明切除请使用普通像素图层；背景层和锁定 Alpha 按 PS 宿主规则处理。玻璃可改变折射后的 Alpha，胶状化会根据轮廓改变 Alpha。PS 选区／羽化由宿主及现有共用预览处理。超出源图的折射采用镜像采样，减少边缘空洞；HDR RGB 保留浮点范围。以上为本项目的适配行为。

已在本机 AE 26.5x89 上读取公开参数并渲染 72 组同源 8 位参考，覆盖平面光照、高光粗糙度、渐变法线／正负高度位移、切除／柔和度、六种通道、点光、彩色灯光和金属。根据输出独立拟合远光方向、镜面项、采样差分和轮廓响应；核心没有调用或读取原版实现。它是参数及视觉重建，**不是任意图像的逐像素一致移植**。柔化、切除边缘、点光及复杂纹理仍存在差异；32 位输出为本机内核扩展，AE 对照采用 8 位。

数值和范围见 `evidence/surface-ae-reference/probe.json`；误差指标、轮廓重叠及明确的近似回归边界见 `evidence/surface-v01/ae-parity.json`。对照图为自制图：每对左侧 AE、右侧本机，上排默认形状，下排点光；不是照片泛化一致性的承诺。验证见 `qa.json`、`任务记录.md`。实际 DLL 覆盖 RGB8/PS16/HDR32、平坦／锁 Alpha、分块／选区保护、命名贴图和错误清理；八组生产界面验证单项／全量重置及取消。24 组串行／并行原始浮点输出逐字节一致。

构建：`surface/build.ps1`；可加 `-CoreOnly` 或 `-BuildTarget Blobbylize/Glass`。沿用主工程 LLVM-MinGW、Adobe 官方 SDK、Dear ImGui 和 `native/build` 共用静态库；缓存运行器增加可选的范围／描述符钩子，其它效果不启用。安装与开发包为整包0.31，验证见 `evidence/surface-manual-0.31/qa.json` 和 `任务记录.md`。0.30的RGB8/16/32、多实例、重启恢复与33份普通滤镜像素检查继续对应相同二进制；历史参考层脚本试验不属于当前发行功能。
