# Chromatic Dispersion（色差色散）0.1

Windows x64 Photoshop 独立滤镜：`ZaYuChromaticDispersion.8bf`。

入口：**滤镜 → ZaYu-AE 效果复刻 → Chromatic Dispersion 色差色散**。运行无需 AE、QCA 或其他第三方效果插件。by：淚泪泪，开源免费。

## 参考与定位

参考 Adobe VR Chromatic Aberration 的通道缩放、兴趣点和衰减，以及 QCA 3 的逐通道位移/旋转/缩放/模糊。算法、代码及光谱近似均为独立实现，未使用其二进制、源码或预设。本滤镜面向 PS 平面合成，未实现 360° 球面/立体 VR 投影。

- [Adobe VR 色差参数](https://helpx.adobe.com/after-effects/desktop/immersive-video-and-vr/immersive-video-effects/vr-effects.html)
- [Plugin Everything QCA 3 功能](https://www.plugineverything.com/qca3)

## 功能

**RGB 分离**：红绿蓝各自具有距离系数、X/Y 位移、缩放、旋转、模糊。独立 RGB 错位之外，也能制作围绕中心的径向和切向色差。

**连续光谱**：使用 380–700nm 的采样位置和 RGB 响应近似，产生平滑彩虹拖尾。8–64 采样、色散曲线、色相、饱和度与柔化可调；每个输出通道的权重分别归一化，保持均匀输入的白平衡。它是基于 RGB 的艺术近似，不能从 RGB 图像恢复真实光谱。

两种模式共用方向角度、距离、混合、中心和可反转的衰减。预览右键设置中心，可开启中心十字显示；中心采用完整文档的归一化坐标，不随预览缩放或选区裁切改变。

预设：镜头色差、RGB 错位、棱镜色散、玻璃高光。玻璃高光默认只处理亮部并保留暗部底图，适合制作参考中的玻璃/高光彩虹效果。源图应有可见亮部；也可以与 Deep Glow 组合使用。

高光阈值/柔和过渡、线性光插值、手动工作伽马；透明/延伸/镜像/循环四种边缘处理；扩展、保留源透明度和黑底不透明三种输出透明度；直接选择现有图层作为 Alpha 或亮度遮罩，支持反转。隐藏采样层可用，引用按唯一名称验证，不需要另存 PSD。

## 共用界面与安全的预览

继承中英即时切换、PS 主题、DPI 字体、关于、折叠滚动参数、缩览图边框、滚轮缩放、拖动平移、适合窗口和“显示背景”。背景仅合成当前图层与下方可见图层，不包含上方遮挡图层。

后台 CPU 预览以 50ms 合并连续操作，计算中保留上一幅完整纹理。视图缩放/平移和背景开关不重算效果参数。PS 回调、通道读取和 GPU 上传只在宿主线程进行，计算线程只访问本次调用内的只读像素快照；替换或关闭任务时取消并等待退出。

预览按可用的原生选区通道混合；若宿主未提供该通道，则显示矩形选区近似提示。最终输出使用 PS 自身的选区处理，不依赖缩览图近似。

## 实现与复用

`native/common/cached_filter_runtime.hpp` 提供可复用的空间效果生命周期：RGB8/PS16/float32 原生快照、命名输入引用、临时参数、全图结果与分块输出、宿主选区、取消与错误清理。`host_read_preview_channel` 扩展共用的只读通道读取，用于选区缩览。新效果无需复制完整宿主适配器。

采样在关联颜色空间中进行；线性光模式同时转换关联 RGB 与覆盖率，最后仅执行一次输出空间转换，避免透明素材的插值光带被再次压暗。完全透明像素的隐藏 RGB 不参与效果。0% 混合精确保留源数据；HDR 浮点 RGB 不在 1.0 处截断。

## 验证与范围

- 内核：精确 RGB 位移、零混合/零位移、均匀颜色/HDR 白平衡、透明/黑底亮度一致、光谱顺序与连续性、中心、通道变换、四种边缘、遮罩、高光底图、alpha 模式、隐藏 RGB、取消、无效参数及原地输出。
- 实际 DLL：RGB8/PS16/HDR32、背景/透明图层、9 个不规则输出块、选区外围与行填充保护、非零 RGB 位移、透明度扩展、选区通道、读错/取消清理、16/32 位坐标。
- 生产窗口：中文与英文、200% DPI、预设/模式、滑块、背景、缩放、右键中心、关于、确定/取消和计算线程退出。
- PS 27.7 实机：RGB8/16/32 的光谱顺序、透明度扩展、一次撤销逐样本恢复、选区外不变、保护透明度、空白透明层、单背景 RGB 文档。见 `evidence/chromatic-host-qa.json`。

输出限于 PS 提供的滤镜作用范围与画布，不能自动扩展画布。RGB/光谱分离是本滤镜的结果，不会生成独立的 R/G/B 图层。8/16 位输出限制在文档允许范围；32 位保留 HDR。单次快照最多 16,777,216 像素。高采样、更大图像和逐通道模糊增加 CPU 时间与内存；尚无 GPU 内核。

未自动解析 ICC/ACES 或 AE 项目色彩管理；工作伽马可手动调整。背景合成沿用共用组件对调整层、图层组及高级混合/剪贴的近似限制。本版未与 AE、QCA 或任何特定第三方效果进行像素级匹配。
