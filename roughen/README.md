# Roughen Edges 毛边 0.1

2026-11-11，整包 0.33 新增的第十九款原生 Photoshop 滤镜。菜单：**滤镜 → ZaYu-AE 效果复刻 → Roughen Edges 毛边**。适合透明文字、Logo、贴纸轮廓、破损边缘及影印效果。

独立重建 AE 毛边的公开参数与八种类型，未使用 Adobe 的原版实现。随机晶格、腐蚀及着色模型仍为近似，同一种子不保证得到 AE 的相同纹理。115 组同源参考记录的是已测范围，并非任意图像逐像素一致承诺。

| 类型 | 行为 |
| --- | --- |
| 粗糙化 | 按透明度轮廓形成随机毛边，低锐度保留柔化 |
| 颜色粗糙化 | 同时给毛边填入边缘颜色 |
| 剪切 | 以更硬的转折切除轮廓，保持原有透明区域 |
| 刺状 | 使用尖化噪声和外缘偏置形成刺状轮廓 |
| 生锈 | 从现有轮廓向内腐蚀 |
| 生锈颜色 | 腐蚀并给受损部分着色 |
| 影印 | 按透明度轮廓形成影印透明区域，适合空心、破损印刷 |
| 影印颜色 | 保持源透明度，将影印区域与边缘颜色混合 |

边缘颜色仅在三种颜色类型中启用。默认棕色 RGB 为 153、51、0。

参数与截图对应：边界 8（0–500）、边缘锐度 1（0–10）、分形影响 1（0–1）、比例 100（10–1000）、伸缩宽度或高度 0（−100–100）、偏移／湍流 0、0、复杂度 2（1–10）、演化 0°、循环演化关闭、循环 1（1–88）、随机植入 0（0–100000）。额外增加效果混合 100%。偏移默认是零，并非画面中心；循环次数仅在开启循环时可调整。

比例控制随机纹理尺寸；伸缩控制水平或垂直的纹理拉伸；复杂度增加细节。演化用于静态形态变化，循环开启后以“循环次数 × 360°”为精确周期。Photoshop 版不提供时间线动画。

使用注意：

- 先将文字或图形转换为智能对象，再添加滤镜，可保留原始内容并重复调整。对完全不透明图片，普通毛边主要出现在画布四周；影印类型也会改变主体填充。
- 边界不是简单的“向内缩小像素数”。低锐度可能产生向透明处延伸的柔边；边界为零也不代表半透明源或影印类型完全中性。效果混合为零才保证源像素完全不变。
- 保护透明度时 PS 保留原 Alpha；普通毛边主要改变 Alpha，因此视觉变化可能很小。背景图层不能存储新透明度，建议转为普通图层或智能对象。
- 支持 RGB8、原生 PS16 和 HDR32；AE 毛边的公开参考仅为 8 位。32 位保留未着色主体的 HDR 色值，着色和影印属于非线性处理，不承诺曝光不变。
- 单次完整源图上限 16,777,216 像素。裁剪范围固定在 Photoshop 提供的源图内，不扩展画布。软边过宽时请给智能对象内容留出透明边距。

界面沿用共享面板：完整分辨率异步预览、背景／缩放／平移、中英文及 DPI。右键预览设置湍流偏移。参数前的蓝色无边框箭头只重置对应参数；底部“全部重置”恢复全部默认值。取消不会提交调整。

智能滤镜完整保存 18 项描述符字段（包括版本字段），支持多个独立实例、PSD 保存及重启恢复。智能对象自身内容保存后由 PS 重新计算；没有外部参考图层或刷新脚本依赖。

性能：每个滤镜调用缓存源图的 Alpha／颜色柔化场；只修改锐度、噪声、颜色等参数时复用缓存，修改边界才重新柔化。按有效 Alpha 区域加边距计算，输出分区并行；预览和确认共用同一核心。缓存不跨文档或调用保留。构建记录中 1024×768 测试约为冷算约 56 ms、缓存计算约 42 ms，具体速度随硬件和参数变化。

验证入口：`evidence/roughen-v01/qa.json`、`ae-parity.json` 与 `任务记录.md`。对照图 `comparison-labelled.png` 每行两种类型，每种左 AE、右本插件；均使用项目自制透明图形，AE PNG 颜色按预乘格式比较。

构建：在项目根目录运行 `roughen/build.ps1`，或加 `-CoreOnly`。需要项目已配置的 LLVM-MinGW、Photoshop SDK、ImGui 和原有共享 UI 库。新增组件只产生 `ZaYuRoughenEdges.8bf`，不修改已有十八款滤镜和公共 UI 库。MIT 开源免费，by：淚泪泪。
