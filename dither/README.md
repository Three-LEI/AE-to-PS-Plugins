# Dither 像素抖动（0.38收录）

**已收录0.38正式版。** 内部组件编号沿用开发编号，发行渠道以整包版本为准。[安装包](https://github.com/Three-LEI/AE-to-PS-Plugins/releases/download/v0.38/AE-to-PS-Plugins-0.38-Windows-x64.zip) · [验证范围](../docs/VALIDATION.md)

用于黑白像素图、有限颜色过渡和规则图案。它与 Halftone 网点印刷、ASCII Dither 字符抖动分别保留为三款滤镜：网点调形状和面积，ASCII 调字符，Dither 在有限颜色之间分布像素。

已纳入0.38正式版。旧滤镜名称、身份与参数保存格式保持。

## 参数

- 算法：有序抖动、Floyd–Steinberg、Atkinson、关闭抖动。
- 有序图案：Bayer 2×2／4×4／8×8、聚集点阵、棋盘、横线、竖线、斜线、十字。
- 调色板：双色、2–16 级灰阶、RGB 每通道 2–8 级、复古绿屏四色、蓝色月光四色、自定义四色。RGB 每通道 2 级即 8 色，8 级即 512 色。
- 像素尺寸、抖动强度、蛇形扫描、明亮度／对比度／伽马／饱和度、线性光近似、二维偏移和效果混合。
- 六组预设：黑白像素、四阶灰度、复古绿屏、蓝色月光、八色像素、图形竖线。预设只设置公共参数。

强度 0 相当于直接限色，100% 为标准抖动，超过 100% 用于强调纹理。蛇形扫描作用于两种误差扩散；有序图案作用于有序抖动。混合 100% 的原尺寸有效像素保持在所选调色板中；降低混合会引入原图颜色。源 Alpha 保留，透明区隐藏 RGB 不污染像素块均值。

支持 RGB8／16／32、中文／English、蓝色单项／全部重置、交互快速预览和精细补全，智能滤镜保存 27 个字段。完整源图上限 16,777,216 像素，网格上限 20,000,000 个单元。

## 预览

原尺寸输出采用清晰的像素块。有序图案缩到单像素以下时，快速预览通过周期阈值图案的面积积分保留平均覆盖率；误差扩散的快速帧使用平均颜色近似。松手后回到完整计算。

窗口缩小查看会按面积平均细像素，因此可见灰色或混合色；这不表示原尺寸的调色板增加了颜色。放大到 100% 可检查实际像素。原图的显示采样在窗口内缓存，避免参数拖动时重复处理相同显示范围。最终 Photoshop 输出不使用显示近似。

双色与固定／自定义四色的有序模式采用临近颜色之间的混合近似。线性光选项使用近似 2.2 传递曲线参与颜色距离与误差计算，不读取 ICC 分色配置。抖动算法与图案为独立实现，不根据参考截图宣称唯一或逐像素复现。

概念参考：[ImageMagick 色彩量化与抖动说明](https://usage.imagemagick.org/quantize/)。本项目不依赖或分发 ImageMagick。
