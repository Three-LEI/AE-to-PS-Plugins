# Saber 0.4：电流光晕（本地测试）

当前本地版本为 [0.6 公共参数版](SABER_UNIFIED_LOCAL.md)，电流、云纹和细丝已接入公共流程，无需切换样式。下文为 0.4 专用样式的历史说明；旧 PSD 保留原流程，可明确转换。

新增 **“电流光晕 / Electric Wisps”** 样式及同名材质预设。在清晰的光核和贴近光核的亮边之外，生成独立扰动的云纹与细丝。原版 Electric 的同圆环参考用于观察结构；参数、随机形态及颜色处理未逐项匹配，不声称逐像素一致或相似度百分比。

**新建滤镜仍默认蓝色基础光束。体验电流材质时，请在“材质预设”按名称选择“电流光晕”。** 原来的电流保留为“经典电流”，其预设显示为“蓝色电流（经典）”；生成行为不变。新的燃烧形态另见 0.5 说明。

## 调整方式

输入继续支持两点、命名钢笔路径、Alpha 轮廓和 Alpha 笔画。透明文字／Logo 想沿边缘发光时选 Alpha 轮廓；已有细线可选 Alpha 笔画。完全不透明的图层会沿画布外框描边。输入和坐标限制见 [输入说明](SABER_LOCAL.md)。

| 控制 | 用途 |
| --- | --- |
| 光核畸变 → 扰动幅度、纹理尺度、细节 | 改变光核的起伏；开放路径端点保持连接。细亮边随光核变化。 |
| 光晕畸变幅度、光晕纹理尺度 | 单独改变外层云纹和细丝的扭曲程度与疏密。 |
| 光晕厚度 | 调整周围纹理的宽度；较大值更接近扩散的云团。 |
| 云纹强度 | 云纹与细丝的整体纹理强度；设为 0 后仍可保留普通光晕及其畸变。 |
| 细丝强度、细丝数量 | 调整纹理中的细线部分；数量为 0 可只看云状部分。 |
| 光晕细节 | 调整外层纹理的层次。 |
| 光晕随机种子、光晕演化偏移 | 选择外层形态，不改变隔离出的光核。 |
| 随机与演化 → 随机种子、整体演化 | 随机种子控制光核；整体演化同时推进光核与外层纹理。 |

“发光”组继续提供近光、四档光晕、预伽马与衰减控制，见 [0.3 发光说明](SABER_GLOW_LOCAL.md)。新电流使用分层发光模型；切换到其他样式后可选择经典模型。原有分叉作为可选光核功能保留，新预设默认关闭分叉。

光核畸变与外层纹理可分别调整；改变轮廓本身、宽度、修剪或 Alpha 阈值仍会同时改变两者的基础形状。近处亮边跟随光核，有助于保留明亮线条。

蓝色单项箭头重置对应参数；“全部重置”回到当前新建默认的基础光束并清除路径快照。调整材质后，可重新选择“电流光晕”预设恢复该预设。拖动时继续使用公共快速预览，停止后精细更新；微小纹理会在精细更新时补足。

## 保存与兼容

共 **57 个效果字段**，原 48 字段 ID 保持不变，另保存 Unicode 路径名与几何快照。新电流使用保存格式 4，需要 **0.4 或更新版本**；旧版本会拒绝读取，避免静默变成旧电流。已有 0.1／0.2／0.3 PSD 保留原来的样式和发光模型，不会自动升级外观。

Alpha 跟随智能对象自身内容更新；钢笔路径仍为快照，修改外部路径后需重新进入滤镜更新。光晕受图层、画布和选区范围裁切，超出边界的纹理无法显示。

本机 PS2020 **21.2.9** 的 RGB8／16／32、参数保存、重开及强制重算，以及旧 0.3 PSD 均纳入本轮验证；0.1／0.2／0.3 共 72 组冻结像素样例保持一致。中英文、中文 200%／旧 DPI 回退、拖动快速帧、松手精细更新和单项重置通过。汇总在 `evidence/energy-v04/qa.json`。

PS2026 **27.7.0** 本轮仅安装。沿用旧主机接口、传统 PiPL 与 DPI 回退；**Win7＋PS2018 19.1.6、其他 Win10＋PS2020 21.2.3 仍待外机复测**。其他 21 款滤镜二进制不变。
