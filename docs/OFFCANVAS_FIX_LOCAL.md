# 图层超出画布 · 公共修复

针对普通像素层移动后，一部分在画布内、另一部分仍保留在画布外时出现滤镜错误，以及首轮补丁中的内容偏移／透明截断问题。0.39正式收录；以下记录0.2修复。

## 修复内容

公共读取范围同时覆盖画布、处理区域和目标层的实际通道边界。Channel Ports按文档坐标读取；当图层超出画布左／上边时，Photoshop的FilterRecord图像从扩展范围左上角重新计数。现统一转换这两种坐标，完整读取后在正确位置分块写回，保留画布外的图层像素。选区开启时floatCoord可能为零，因此转换依据目标通道边界，而非单靠floatCoord。

统一修正缓存型滤镜，并补齐Glow／Deep Glow、Displacement Map的独立入口；Cell Pattern与Grid／Checkerboard生成／源混合也使用同一文档坐标。对应预览范围、外部参考层和最终输出坐标保持一致。

0.39包含当前31款滤镜。修复首次验证覆盖当时的29款：27款重新链接公共坐标修复，Tint／Fractal Noise原生输入输出分块入口保留原二进制；此后新增的Film Damage与Long Shadow沿用同一路径，并在各自验证中检查画布外坐标。效果核心、参数字段／身份及嵌入元数据保持；普通图层无需先转换为智能对象。

## 安装

退出Photoshop，将修复包 `Plug-ins` 中的同名 `.8bf` 替换到插件目录后重启。维护者本机版本已先备份，再替换到PS2020／2026。旧版独立试用包保留。

这是本机补丁，不是GitHub新正式版。不要与多个目录中的重复旧插件混用。

## 验证与边界

测试包含实际DLL的新旧坐标接口、RGB8／16／32、四方向越界和画布内选区；Tint维持仅RGB8。另在PS2020 21.2.9上验证普通像素层、选区、撤销及正常画布内的旧／新像素对照。第二轮记录保存在研究工作区 `evidence/offcanvas-v02`。

首轮595个宿主用例只验证不报错，未验证隐藏像素和位置，因此不能证明首轮补丁完整。第二轮加入真实PS的重定位坐标模型、恒等输出逐像素检查，并对23款可设置为原图输出的效果执行“移动→应用→移回”对照，检查四向越界、选区和透明标记；旧补丁会在这些检查中失败。完整用例数与结果见工作区的host-results.json与qa.json。

第二轮全部29款实际DLL的1,456个用例／7,626,774项检查通过；PS2020的680个效果／位深／位置／选区用例和536组移回后的像素对照通过，没有隐藏像素丢失或额外位移。85组正常画布内新旧输出逐像素一致。Fractal Noise原本会填充Alpha，恒等对照采用不透明输入；其余22款使用透明标记。生成行为不作改动。

不改变既有内存保护与效果生成算法。极大图层仍受各效果的输入尺寸和可用内存限制。PS2026本轮仅安装；Win7／CC2018保留旧加载和DPI路径，仍需外机复测。

外部参考层已另行更新为按图层自身边界读取，见[完整参考图层](REFERENCE_LAYERS_LOCAL.md)。
