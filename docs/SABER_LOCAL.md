# Saber 能量光束：0.2 本地测试

当前本地版本为 [0.6 公共参数版](SABER_UNIFIED_LOCAL.md)，新建效果无需切换样式；旧 PSD 保留原行为，可明确转换。下文为 0.2 历史参数说明，其中输入与坐标限制继续适用；电流、燃烧和存储字段数量以当前版本说明为准。

以 AK / Video Copilot Saber 为目标的独立实现。**0.2-local** 新增 Alpha 输入、电流和火焰风格，原有基础光束的默认生成结果保持不变。只在本机开发和测试，未提交 GitHub、未发布 Releases。

**材质进度说明**：0.2 的电流和火焰是初步风格，与原版仍有明显差距。安装原版后已建立同圆环实机对照，后续先校准基础发光，再做独立光晕畸变与燃烧结构，见 [原版材质研究](SABER_MATERIAL_REVIEW.md)。该研究没有更改当前安装版本。

## 输入和样式

| 输入 | 用途 |
| --- | --- |
| 两点光束 | 用左键分别拖动预览中的两个端点，也可直接输入坐标。放大后从空白处拖动可平移。 |
| 钢笔路径 | 读取命名路径，支持贝塞尔控制柄、开放／闭合子路径及多个轮廓。 |
| Alpha 轮廓 | 自动描出当前滤镜输入的透明边缘，包含文字、Logo 内部孔洞；Alpha 阈值控制边界。 |
| Alpha 笔画 | 直接把原始 Alpha 覆盖作为光核，适合已画好的细线，保留原笔画宽度。 |

输入和样式独立选择。基础光束沿用核心宽度、亮度、核心白度、颜色、光晕半径和强度；电流增加扰动、纹理尺度、细节、路径分叉和分叉长度；火焰增加方向性焰体、高度、飘动及外焰颜色。

提供蓝色光束、蓝色电流、橙色火焰三个材质预设，切换预设保留输入、端点、路径快照、修剪、偏移和 Alpha 阈值。随机种子和演化可手动选择形态，并随 PSD 保存。PS 中生成静态图像。

所有模式沿用快速预览，停止调整后自动精细更新；参数支持蓝色单项重置，全部重置恢复所有参数。路径的单项重置会清除快照。

## 建议先这样测试

1. 准备 RGB 像素图层，需要后续编辑时先转换为智能对象。
2. 打开“滤镜 → ZaYu-生成 → Saber 能量光束”，先用两点光束测试三个材质预设。
3. 抠好的文字或 Logo 选择 **Alpha 轮廓**；已画好的细线选择 **Alpha 笔画**，无需先转换工作路径。
4. 电流调整扰动和纹理尺度；火焰调整高度、方向和飘动。改变演化或种子选择其他形态。
5. 保存 PSD，关闭重开后双击智能滤镜继续修改。

Alpha 输入使用当前滤镜收到的图层像素，不读取外部参考层。完全不透明的图片会沿画布外框生成轮廓，需先抠出透明区域。笔画模式使用原始宽度，不使用路径的弧长修剪、渐细和分叉。

## 更新与保存

**Alpha 输入**每次从源像素计算；修改智能对象自身内容并保存后，Photoshop 会自动重新计算，本轮已用实际源内容编辑验证。无需刷新脚本。

**钢笔路径**保存几何快照；修改外部路径后重新进入滤镜点击“更新路径”。重命名或删除外部路径不会破坏快照。非交互路径回放必须携带快照，建议在界面选择路径后录制动作。

35 个效果字段、Unicode 路径名和快照均可保存在 PSD。保留 0.1 的 20 个字段 ID 和参数块迁移，旧 PSD 按原基础光束还原。新 Alpha／材质使用保存版本 2，**需要 0.2 或更新版本**；0.1 会拒绝读取，避免静默变成普通光束。

## 范围与限制

- 数值以滤镜输入的原始像素为单位；快速预览降采样不写入参数，也不改变最终分辨率。
- 输出受图层、画布和选区范围限制，超出输入画布的光晕或火焰会裁切。
- 路径最多 16,384 节点、4,096 子路径；Alpha 轮廓简化前最多 262,144 条边，简化后使用同样节点限制。超过时拒绝处理，不截断轮廓，可改用简化后的工作路径。
- 变换智能对象与外层文档路径之间仍没有自动坐标换算。外部路径建议在智能对象内容文档内建立和应用；Alpha 从对象自身像素提取，可省去外部路径的对应步骤。
- 电流和火焰为独立实现的风格，完整原版材质库、烟雾及其他预设可后续扩展。

## 验证与安装

本机 PS2020 **21.2.9** 验证 RGB8／16／32 的真实输出、撤销、独立智能滤镜实例、旧版 PSD、重启后重开和强制重算，以及 Alpha 源内容更新和恢复。中英文、中文 200%／旧 DPI 回退、连续快速帧和松手精细更新检查通过。

0.1 基础模式的 24 组冻结样例逐像素一致，其他 21 款二进制不变。沿用传统 PiPL/aete、旧描述符接口、预编译着色器和 DPI 回退；PS2026 本轮仅安装，**Win7 + PS2018 19.1.6、其他 Win10 + PS2020 21.2.3 仍需复测**。

测试包 `dist/AEPS-Saber-local-0.2.zip` 仅含 `Plug-ins/ZaYuSaber.8bf`。退出 PS，备份旧同名文件，覆盖后重启。无需覆盖其他插件；0.1 测试包保留供回溯。
