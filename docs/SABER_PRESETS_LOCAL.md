# Saber 0.7：16 款自有预设（本地测试）

在 0.6 公共流程上增加 12 款预设，共 16 款。原有默认光束、电流、燃烧、混合的参数保持不变；没有增加材质类型开关或修改生成内核。选择预设后，仍可使用同一组公共控制自由调整。面板中间的公共参数说明文字已移除。

| 新预设 | 起始风格 |
| --- | --- |
| 薄荷细光 / Mint Thread | 细而干净的薄荷绿光线、窄光晕。 |
| 玫瑰霓虹 / Rose Neon | 清晰粉色霓虹与较宽柔光。 |
| 金色电弧 / Golden Arc | 带短分叉的金色电弧。 |
| 冰霜 / Frost | 细碎冰蓝纹理、尖锐起伏和短分叉。 |
| 紫雾 / Violet Mist | 弱光核与宽阔紫色云纹。 |
| 幽绿 / Venom | 明亮绿色光核及较浓的绿色外围。 |
| 熔岩 / Lava | 较粗的橙红光核与密集破碎纹理。 |
| 日冕 / Solar Corona | 金色光核、宽阔暖色云团和细丝。 |
| 等离子 / Plasma | 紫色畸变光核与密集蓝紫细丝。 |

这些名称描述本项目静态风格，不代表原版同名材质或物理模拟。圆环、直线、路径和透明文字会呈现不同形态，光晕也受图层、画布和选区范围裁切。

## 使用

在新建 Saber 的“预设”菜单中选择；列表可滚动。选择预设保留输入、端点、路径快照、修剪、渐细、效果偏移和 Alpha 阈值，重设外观参数。默认仍是原来的基础光束，“全部重置”也恢复基础光束，不恢复最近选中的预设。

旧 0.1～0.5 实例继续保留旧界面；先点“转换为公共参数”才能使用公共预设。转换前请检查预览，取消保留原参数。公共参数、转换及四种输入见 [0.6 说明](SABER_UNIFIED_LOCAL.md)。

预设直接保存为已有 70 个效果字段的数值，保存格式仍为 **6**，没有新增预设编号字段。0.6 可按自定义参数还原新预设的效果；较早版本不能读取公共格式。新建预设不改变默认值，也不改变现有 PSD 的外观。

本轮还通过公共界面库把各滤镜操作按钮加高到至少 26 个逻辑像素，并同步使用实际按钮高度预留底部空间，数值参数行保持紧凑。布局验证见 [按钮说明](UI_BUTTONS_LOCAL.md)。

本机 PS2020／PS2026 均已备份更新，记录分别见 `evidence/ui-buttons-v01/installed-2020.json` 和 `installed.json`。PS2026 27.7.0 完成三位深、新进程参数恢复和强制重算验证；PS2020 21.2.9 完成三种位深加载、参数保存及同进程重开简测。Win7＋PS2018、外部 Win10＋PS2020 仍待复测。

只更新 Saber 可使用 `dist/AEPS-Saber-local-0.7.zip`；全部插件的按钮更新使用本轮整包。退出 PS，备份同名文件后替换 Plug-ins 中的 `.8bf`，再重启。历史包保留，**未提交 GitHub、推送或发布 Releases**。
