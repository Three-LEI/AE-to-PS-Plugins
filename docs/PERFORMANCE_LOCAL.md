# 公共计算与预览优化（本地候选 0.9）

本地整包共 23 款滤镜。已安装到本机 Photoshop 2020／2026，未提交 GitHub、推送或发布 Releases。当前公开版本号保持不变。

## 本轮变化

- **线程复用**：预览工作线程在窗口内保留一组计算线程；多阶段最终渲染在一次生成内复用。完成通知会立即唤醒调用方，取消回调仍由调用线程执行。每次任务继承调用方的浮点环境，计算分区和逐像素运算顺序保持。关闭窗口或完成生成后回收线程，DLL 静态对象不持有后台线程。
- **临时内存复用**：Glow／Deep Glow 的多次模糊共享输出和前缀和缓冲区，减少每一遍的重复申请；生成公式和模糊步骤保持。
- **分层缓存**：公共 `StageCache` 首先用于 Glow／Deep Glow。修改非零曝光／强度、着色、纹理合成等参数时，可复用已经完成的高光与模糊。半径、阈值、工作伽马、遮罩等前置条件变化时重建。Deep Glow 的滤色与相加、零强度和源视图分别判断，避免复用错误结果。原有 Starglow／Shine 高光提取缓存继续保留。
- **内存限制**：每个发光窗口最多保留两组中间结果，图像缓存合计上限 96 MiB；超限时使用直接计算。取消的中间结果不会进入缓存，重新读取参考层及关闭窗口时释放缓存。最终 Photoshop 输出仍直接按原图与原参数计算。

参数结构、事件、参数字段、默认值及智能滤镜保存格式保持。缓存只在窗口内使用，不写入 PSD。

## 合并上一轮预览画质改进

采用用户选择的画质与流畅度平衡设置：草图初始最长边 512，按实际计算时间在 256／384／512／768 间调整；停止调整约 180ms 后回到精细预览。透明区域采用预乘 Alpha 采样，减少细边色晕。

百叶窗快速预览单独计算条纹遮罩，再作用于原图；照片和细文字的 RGB 不再随草图一起模糊。原尺寸输出保持原有路径。六组合成素材测试的平均预乘 RGB 误差较旧 256 草图下降约 80.8%，该数字只代表这些测试样例。

## 本机测量

以下是自有合成图的 CPU 核心耗时，采用相同输入，预热后取三次中位数；不包含 Photoshop 读取图层、界面显示和保存文件。线程调度、系统计时精度、图像与参数均会影响收益，不能按此表推断所有素材。

| 测试，512×384 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 百叶窗，带羽化 | 85.3 ms | 4.1 ms |
| Glass | 88.0 ms | 5.8 ms |
| Saber，基础公共流程 | 339.4 ms | 22.6 ms |
| Shine | 66.7 ms | 12.8 ms |
| Deep Glow，直接完整计算 | 282.2 ms | 256.3 ms |

Deep Glow 768×512、半径 100 的连续非零曝光调整，在同一测试进程内平均每次直接计算约 **351.3ms**，命中缓存后约 **19.5ms**，保留的图像缓存为 12 MiB。首次打开及改变半径等前置参数仍需要完整计算。

## 验证与兼容边界

- 16 个模块完整构建及原有核心、真实 DLL、参数与适配检查通过；38 个原有参数／宿主头文件哈希保持。
- 36 组完整浮点输出与优化前逐字节一致；396 组缓存／直接输出对照通过，全部参数变体同时对照冻结的优化前 Glow 内核。
- 46 组中英文、100%／200% 与旧 DPI 路径界面检查通过，覆盖连续拖动、停止后补全、重置、取消和布局；公共预览 66,120 项检查通过。
- 本机 PS2020 21.2.9：23 款共 67 个效果／位深组合、67 次撤销通过；137 次 TIFF 样本字节比较与安装前一致。
- 旧 PSD 回放覆盖原 19 款、Saber 和百叶窗：97 个效果／位深图层组合，194 个独立智能滤镜实例、194 次重开／强制重算图像比较通过。Starglow／Shine 本轮完成普通输出和界面检查，沿用此前的 PSD 保存验证。
- 23 份 PE 均保留 x64、OS／Subsystem 6.0 和 PluginMain；相对上一版没有新增强制导入 API。保留 Win7／CC2018 的注册、DPI 和预编译着色器兼容路径。**本候选仍需在外部 Win7／PS2018 复测**；用户之前确认的是 0.7 整包。PS2026 本轮仅安装，未增加实机回归声明。

效果计算仍使用 CPU，GPU 用于界面和预览显示。完整证据位于 `evidence/performance-v01/qa.json`；上一轮画质研究位于 `evidence/preview-quality-v01`。

## 试用与回退

本机 PS2020 和 PS2026 的同名插件已备份后更新。可优先试用带羽化的百叶窗、Glass、Saber，以及 Deep Glow 的曝光与着色拖动，再改变半径检查重新生成。

独立测试包为 `dist/AEPS-Performance-Preview-local-0.9.zip`。其他电脑请先退出 Photoshop，备份旧插件，再覆盖包内 `Plug-ins` 的同名 `.8bf`，避免不同插件目录留有重复副本。本机回退文件位于 `evidence/performance-v01/installed-before/2020` 与 `2026`；回退也需要先退出 Photoshop。

下一阶段可按实测瓶颈扩展其他效果的参数依赖缓存，再评估带外围补偿的视口计算。GPU 生成保留为后续独立研究。
