# Saber 原版材质对照：2026-11-13（仅本地研究）

后续进度：本研究后的第一步已接入 [0.3 基础分层发光](SABER_GLOW_LOCAL.md)。下文保留研究当时的 0.2 对照与判断。

已确认用户新安装的原版可以在 AE2025 中加载。此前未检测到插件是安装时间所致。原版信息为 AE **25.6.5x3**、Saber **1.0x40**，公开效果标识 `VIDEOCOPILOT LightSaber`。本轮建立实机对照，**没有升级或重新安装 PS 插件，没有提交 GitHub 或发布 Releases**。

## 当前判断

0.2 已完成两点／钢笔路径／Alpha 输入、参数保存和快速预览这些基础能力；电流和火焰仍是初步的独立风格，不能称为原版材质的等效复刻。用户指出的视觉差距成立。

![原版与当前 0.2 的同圆环对照](../evidence/saber-material-review/comparison.png)

上排是原版预设，下排是当前 0.2 自有预设。两边几何相同，**预设参数、演化相位及跨宿主颜色处理没有逐项对齐**；此图用于判断结构和风格，不用于计算像素误差或声称复刻百分比。基础预设的亮度、宽度差别有参数因素，不能全部归因于算法。

观察结合当前源码，可定位以下问题：

- **基础发光**：原版默认有宽阔的蓝色光晕；当前默认更收敛。0.2 使用固定三档权重的模糊叠加，原版公开控制中有四组发光半径／强度、预伽马和 Halo。需先校准这些可见控制的响应及明暗衰减，不能仅提高总体亮度。
- **Electric**：原版样本的细光核周围有破碎、弯曲的云状光晕。当前沿路径的扰动与分叉生成了线条，光晕仍主要来自对该线条的模糊，缺少可独立变化的周边纹理。
- **Burning**：原版样本的火光围绕路径展开，并有局部细丝和烟状结构。当前沿单一方向传播热量，容易形成朝上拉伸的大片黄色焰体；这属于生成方式的差异。
- **Fog**：原版样本以柔软、暗淡、断续的轮廓为主，当前没有对应材质。应在独立光核／光晕畸变成立后处理。

用户给出的预设缩略图还包含明显的头尾变化；本轮完整圆环的原版 Default 则基本均匀。不能把缩略图中的所有头尾特征都当成每种材质的固有行为，后续应另行测试修剪、端部尺寸和场景设置。

## 原版公开参数取样

通过公开脚本接口读取了 **94 个顶层属性条目**，递归记录共 **97 条**，包括分组和 AE 自带选项，并非 97 个独立数值参数。公开预设菜单可以切换并联动参数。本轮每个预设都从新建的原版效果实例开始，避免继承上一预设的残留设置；渲染前后参数快照完全一致。

## 下一阶段顺序

1. **先完成基础光核与发光校准**：分别建立光核、贴近光核的 Halo、远处光晕；独立控制宽度、强度和衰减，验证四档发光及预伽马的用途。先用无畸变圆环和直线校准，避免让发光误差遮盖材质误差。
2. **再做 Electric 的独立光晕畸变**：保留可辨认的细光核，让周围二维纹理单独扰动；多条细丝和局部强弱变化应可控制。保留现有分叉作为可选功能，不能只靠增加分叉数量接近原版。
3. **再做 Burning，最后扩展 Fog**：在路径周围生成可扰动的发光场，使火光包裹路径，并可叠加风向；减少现有大片填色感。先将一个燃烧材质做清楚，再扩展相近预设。

上述是基于样本和公开控制提出的实现方案，不是对原版内部算法的断言。暂不批量添加预设名称，也不承诺逐像素一致。

新引擎须作为可区分的版本保存；旧 0.1／0.2 PSD 应继续使用旧生成行为。保留现有公共快速预览、参数持久化和兼容接口。完成后需要核对闭合圆环、开放曲线、文字内孔、Alpha 笔画，以及快速预览与最终输出的形态稳定性；继续覆盖 RGB8／16／32、重开 PSD、确定性和旧版冻结样例。Win7／PS2018 与其他 Win10／PS2020 的兼容范围沿用现状，不能以本轮 AE 研究替代外机复测。

## 证据与复现

- 原版圆环：384×384，圆心 `(192,204)`，半径 88，四段贝塞尔；25fps 的第 12 帧（0.48 秒）。Core Type 为经输出确认的遮罩路径模式，遮罩自身不裁剪黑色源图层。
- AE 工程为本轮自己创建的 `ae-reference-owned.aep`／`ae-render-owned.aep`，脚本遇到其他工程会停止；没有打开或修改用户工程。
- AE 工程为 32bpc、Working Space=None、未启用线性工作空间／线性混合；输出模板为 **8 位 RGB+Alpha TIFF**，PNG 仅供查看。尚未建立 AE／PS 统一的线性 HDR 校准流程。
- 最终原版取样记录：[ae-render-1794502146318.json](../evidence/saber-material-review/ae-render-1794502146318.json)，原始帧与 PNG 在 `evidence/saber-material-review/native-1794502146318/`。早先试跑保留，不作为最终基线。
- 当前 PS 核心的同圆环样本由 [energy-circle-baseline.cpp](../qa/energy-circle-baseline.cpp) 生成，没有通过改参数覆盖现有插件。
- [review-checks.json](../evidence/saber-material-review/review-checks.json) 记录参考帧、源码与产物哈希；**22 个生产插件二进制与研究前完全一致**。公共发布目录仍为干净的 `cf063c8cffd3207a60f606a40050206eeacc1f8e`，无提交／推送。

当前环境下，在 AE 仅打开上述自有工程时运行 `qa/saber-ae-render-reference.jsx`；随后执行 `./qa/build-saber-material-review.ps1` 与 `python ./qa/verify-saber-material-review.py`。参考脚本使用本机项目绝对路径和原版插件，复用到其他环境需调整路径。每次输出到新目录，不覆盖旧参考帧；本轮原版输出仅用于本地对照，不加入发行包。
