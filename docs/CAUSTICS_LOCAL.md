# Caustics 焦散 0.2

0.39正式收录（第29款效果／第22个模块）。滤镜名称 **Caustics 焦散**，菜单为“滤镜 → ZaYu-AE 效果复刻”。支持 RGB8／16／32 和智能滤镜参数保存。

## 0.2 本机更新

**新实例默认同时产生背景折射和焦散光纹**，折射扭曲默认100%。适合直接应用到照片或其智能对象。顶部输出选择“与源图合成”时才扭曲底图；纹理、透明光纹、高度图输出只生成对应素材。水深和折射率同时影响光纹，仍可在所有输出模式调节。

已有0.1智能滤镜按原参数重开，不自动改变其外观。如果原实例折射为0，可将“折射扭曲”设为100%，或选择“水下折射”预设；需要恢复新的默认值时使用“全部重置”。

并行生成光线贡献，按原有顺序累计，保持相同参数的输出；预览缓存水波、光纹与折射底图。调整颜色、强度、阈值、混合和透明度等后期参数时可以复用，几何或参考快照变化时重算。缓存仅在窗口生命周期内存在，最多两组、合计96MiB，超限走正常计算。确认时完整重算，不依赖预览缓存。

1024×768合成输入、开启100%折射、各阶段5次中位数：旧核心约400.7ms，新完整核心约160.8ms；缓存命中调整光纹强度约8.3ms。未计Photoshop读取、色彩转换和显示时间；实际速度随尺寸、参数和电脑而变。

150组缓存／直接／冻结0.1完整浮点对照逐字节一致，另有174项缓存依赖／预算／取消／舍入检查。PS2020重新核对0.1的36个旧智能实例及新建36个实例，两组均有54项像素回放和18项独立核心对照；默认折射及窗口缓存命中已由实际生产界面测试覆盖。32字段、事件和保存块布局保持。

## 使用

- 给画面叠加水光：选“仅叠加水光”（折射扭曲为 0），调节水波尺寸、波高、聚焦倍率和光纹强度。
- 制作水下效果：选“水下折射”，通过水深、折射率与折射扭曲调整图像变形；光纹强度可以单独降低或关闭。
- 制作独立素材：输出选“焦散纹理”或“仅光纹（透明）”。在空白透明层上生成时，关闭“保留源透明度”；要铺满画布，可先使用画布大小的像素层或智能对象。
- 自定义水波：水波来源可选当前图层或外部参考层，支持亮度、RGB与Alpha。选择“水面高度图”可以检查高度来源。参考层的位移和内容取当前快照，修改后重新进入效果确认刷新。避免同名参考层；缺失或重名会报错，重新选择即可。

七套自有预设：清澈水光、深池光纹、暖阳水光、水下折射、同心涟漪、细碎光网、仅叠加水光。预设只调整公开参数，保留已选的高度来源与位置；第一次从零偏移切到同心涟漪时，将中心放到图像中央。没有使用原版预设文件。

## 参数

内置水波有自然水波、交错波浪、同心涟漪三种；尺寸、复杂度、演化、波高、偏移和种子控制形态。外部高度图有平滑与通道选择。水深及折射率影响光线偏折，聚焦倍率控制光纹汇聚，折射扭曲独立控制水底图像。

采样质量提供标准／精细／最高。光纹强度、阈值、柔化和颜色可单独调节；合成有滤色、相加、水底照明和叠加。另有源图亮度、暗部颜色、保留源透明度与整体混合。相加和水底照明在 RGB32 中保留 HDR，不限制为 1。

公共界面支持蓝色单项重置、全部重置、语言／DPI、面积采样显示和自适应预览。快速帧保留原文档的水波尺度、参考层坐标和光学参数；停止拖动后补全，确认后重新进行完整计算。随机种子固定时结果可重复。

## 实现与限制

CPU 根据高度梯度计算折射方向，并向底面投射、累计光线；图像折射共用高度场，通过反向采样生成。均为二维高度场近似，没有三维场景、遮挡、天空环境反射、色散、多次反射或液体动力学。与两款原版不保证逐像素一致。

单次偏移上限为 512 原生像素，以控制外扩计算和极端参数的开销；最高采样在超大尺寸下有总射线预算保护。不是完整三维光线追踪。不会自动扩展 Photoshop 画布，受图层／智能滤镜作用范围及 PS 选区限制。

当前单张输入最多 16,777,216 像素，与现有缓存型滤镜的核心保护范围一致。水波尺寸与水深使用原生像素，改变文档尺寸时可能需要调整。涟漪中心由水波偏移控制。

外部层按名称保存绑定，重命名、删除或出现同名层后需要重新选择。与 Glass 一样，外部层修改不会触发自动依赖刷新。不安装额外刷新脚本。
