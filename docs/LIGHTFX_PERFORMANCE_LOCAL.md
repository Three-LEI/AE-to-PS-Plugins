# 星芒与放射光束性能优化（0.38收录）

**已收录0.38正式版。** [下载安装包](https://github.com/Three-LEI/AE-to-PS-Plugins/releases/download/v0.38/AE-to-PS-Plugins-0.38-Windows-x64.zip)；本文件名沿用开发阶段命名。`evidence`／`dist`路径为维护者本地历史记录，公开验证见[VALIDATION.md](VALIDATION.md)。

该优化基于0.37开发，更新Starglow与Shine；0.38收录这两个程序及五款新增效果，其余21款原有程序保持。

## 本轮改动

- 星芒的斜向光线按不重叠的区域分配给 CPU 工作线程。保留各方向的累加顺序和每条线的计算顺序，首次生成和改变方向／长度时也可受益。
- 两款效果在已有高光提取缓存之后，共用公共 StageCache 保存光线结果。调整源不透明度、光效不透明度、效果混合、混合模式和保留源透明度时，可以跳过光线生成。
- 长度、方向、颜色、光强、阈值等前置参数仍会触发重算。改变草图尺寸或高光源快照时清理缓存；窗口关闭时释放。缓存不写入 PSD，Photoshop 最终输出仍使用直接完整计算。
- 新增光线缓存最多保留两组结果、共计不超过 96 MiB；单帧超限时回退直接计算。并行时每线程的斜向插值临时区最多 4 MiB；超出这一规模的极长窄图沿用串行。继承已有线程数限制，最多八个计算分区。

没有改动参数结构、默认值、预设、保存格式、组件身份或效果公式。旧系统的 PiPL/aete、DPI 回退和预编译界面着色器保持。

## 测量

同一自有 HDR／透明合成输入，1024×768，纯 CPU 核心计算；预热后三次或五次取中位数，不含 Photoshop 图层读取、启动、界面显示和文件保存。

| 场景 | 优化前／直接计算 | 优化后／缓存命中 |
| --- | ---: | ---: |
| 旋转 17° 星芒，完整计算 | 273.8 ms | 134.1 ms |
| 星芒，已提取高光后调整光效不透明度 | 129.5 ms | 10.5 ms |
| Shine，已提取高光后调整光效不透明度 | 42.8 ms | 13.5 ms |

后两行比较本轮直接计算与本轮缓存命中；星芒直接计算已经包含并行优化，不能与第一行混为同一项收益。性能随素材、参数、图像尺寸和 CPU 变化，不代表整个 Photoshop 操作均能达到相同倍数。

同轮还测量了 Saber 的基础／复杂公共预设、色差色散的不同模式和 Glass。本轮优先修改旋转星芒；Saber、色差色散及 Glass 程序保持。完整 20 组测量和输出位于本地 evidence/performance-v02。

## 使用与验证边界

本机 PS2020 21.2.9 与 PS2026 27.7.0 已备份安装这两个滤镜。PS2026 本轮仅安装；Win7／CC2018 仍需外部机器复测，静态依赖检查不能替代实机验证。

可优先试用星芒旋转方向、光效不透明度和混合模式，观察停止拖动后补全精细预览；Shine 可试光效不透明度与效果混合。新的光线缓存不覆盖移动 Shine 中心点，因为中心变化会改变光线几何。

从[0.38安装包](https://github.com/Three-LEI/AE-to-PS-Plugins/releases/download/v0.38/AE-to-PS-Plugins-0.38-Windows-x64.zip)安装两款效果。退出Photoshop后备份同名文件再覆盖。

266 组缓存／直接／冻结内核对照、20 组完整浮点输出对照和四组生产窗口交互检查通过。PS2020 的 48 次 TIFF 像素比较与冻结的 0.37 程序一致，12 个旧智能滤镜实例的参数恢复通过；两款 DLL 的导入表及全部嵌入资源保持。详细记录见本地 evidence/performance-v02/qa.json。

历史 lightfx-v01 的星芒合成图早于之前的算法修正，本轮通过冻结的 0.37 程序重新取得宿主基线，比较本轮输出；历史图片差异不归为本轮性能优化。
