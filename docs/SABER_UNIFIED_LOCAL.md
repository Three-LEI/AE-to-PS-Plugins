# Saber 0.6：公共参数与预设（本地测试）

当前本地版本为 [0.7 预设扩展](SABER_PRESETS_LOCAL.md)，共有 16 款自有预设。下文的公共参数、转换及保存格式继续适用，原有四款预设数值保持不变。

新建 Saber 使用同一条生成流程。**默认光束、电流、燃烧、混合只是一组公共参数值，不再选择不同的材质生成器。** 不选择预设，也能直接组合光核畸变、外围畸变、云纹、细丝、风和色彩过渡。旧版智能滤镜继续保留原来的生成流程，需要手动转换后才进入新面板。

这是一套独立实现的参数和算法，不与原版 Saber 的参数数值或噪声形态直接对应；没有移植原版代码、着色器或私有预设。新增烟雾专用预设等工作留待后续。

## 先这样测试

1. 在新建智能对象上应用“滤镜 → ZaYu-AE 效果复刻 → Saber 能量光束”。默认得到基础蓝色光束。
2. 不切换预设，展开“外围畸变与纹理”，增大“云纹强度”或“细丝强度”，就能叠加对应纹理；细丝无需先开启云纹。
3. 分别调整光核与外围的噪声类型、幅度、尺度和细节。光核控制亮线形状，外围控制周围光晕及纹理。
4. 展开“风”调整风力与方向；即使云纹、细丝为零，普通外围光晕也可以被风推动。
5. 展开“色彩过渡”，增大过渡强度并调整外围颜色，即可让较弱的外围光向第二种颜色过渡。

也可以先选择“电流”“燃烧”或“混合”预设，再调整同样的参数。**选择预设会重设外观参数，保留输入、路径快照、两端点、修剪、渐细、效果偏移及 Alpha 阈值。** 调整后的预设显示为自定义。

## 公共控制

| 参数组 | 作用 |
| --- | --- |
| 核心 | 主颜色、宽度、亮度与核心白度。Alpha 笔画使用原始覆盖宽度。 |
| 发光 | 近光、总体光晕、预伽马与四档范围／强度，延续分层发光控制。 |
| 光核畸变 | 平滑／分形／尖锐噪声、幅度、尺度、细节、种子和整体演化；路径输入还可增加分叉。开放路径端点保持连接。 |
| 外围畸变与纹理 | 独立噪声类型、幅度、尺度、细节、种子、演化偏移、纹理厚度、云纹强度、细丝强度和数量。 |
| 风 | 风力与方向只推动外围，不移动光核。 |
| 色彩过渡 | 过渡强度与外围颜色；任意预设都可使用。 |

“整体演化”同时推进光核与外围，“外围演化偏移”只选择外围形态。光核和外围可以选用不同噪声类型。改变输入轮廓、宽度、修剪或 Alpha 阈值，仍会改变两者共用的基础形状。

只看光核时，把光晕强度、近光强度、云纹强度和细丝强度都设为零。蓝色单项箭头恢复对应参数；“全部重置”恢复公共版的新建默认值，并清除路径快照。拖动时降低预览分辨率，停止后自动恢复精细结果，最终输出始终使用原始尺寸。

四种输入继续支持两点光束、钢笔路径、Alpha 轮廓和 Alpha 笔画。Alpha 轮廓适合透明文字／Logo 的边界；完全不透明的图层会描出画布边框。输入、坐标与路径更新方式见[输入说明](SABER_LOCAL.md)，分层发光含义见[发光说明](SABER_GLOW_LOCAL.md)。

## 旧 PSD 与保存

打开 0.1～0.5 的智能滤镜，默认保留旧界面和外观。面板上方有“转换为公共参数”按钮：

- 转换会保留输入、路径快照及几何设置，并把旧外观参数映射到公共控制；经典电流／火焰等映射可能改变外观，请检查预览。
- 点“取消”会保留原参数与路径；点“确定”才将转换结果写回该实例。转换后再点“全部重置”，得到公共版默认值。
- 想先保留旧效果作比较时，可以先复制图层或智能滤镜实例。旧版内部生成流程仍保留，不会因安装更新自动转换。

公共版使用保存格式 **6，需要 0.6 或更新版本**。原 66 个效果字段的顺序与 ID 保持不变，追加 4 个字段，共 70 个存储字段；其中包含仅供旧版兼容的数据，并非 70 个公共可见控件。Unicode 路径名与几何快照另行保存。旧格式仍可读取；旧插件不能用于编辑公共版实例。

Alpha 随智能对象自身内容更新；外部钢笔路径仍保存为快照，修改外部路径后需进入滤镜“更新路径”。普通像素层直接应用只留下栅格结果，需要保留可编辑参数时请使用智能对象。

## 验证范围与限制

- 本机 PS2020 **21.2.9** 验证 RGB8／16／32 普通输出、撤销、48 个智能滤镜实例、新进程重开／强制重算及 Alpha 源内容更新；旧 0.5 PSD 的重开和强制重算也保持一致。
- 0.1～0.5 共 **120 组冻结样例逐像素一致**；公共版的 8 组串行／并行结果一致。单独复写公共可见参数能重现每个预设，无需样式开关。
- 中英文公共面板的直接拖动、快速帧、停止后精细更新和单项重置通过；旧界面的取消、明确转换、路径保留及全部重置通过。
- 本机 PS2026 **27.7.0** 本轮仅安装；沿用传统 PiPL、旧接口与 DPI 回退。**Win7＋PS2018 19.1.6、其他 Win10＋PS2020 21.2.3 仍需外机复测**。其他 21 款滤镜二进制未改。
- 图层、画布和选区仍会裁切越界光晕。变换智能对象与外层文档路径之间没有自动坐标换算；路径复杂度限制沿用输入说明。

## 安装与开发

本机 PS2020／PS2026 已单独备份并替换 Saber。测试包 `dist/AEPS-Saber-local-0.6.zip` 只含一个滤镜：退出 PS，备份旧文件，把 `Plug-ins/ZaYuSaber.8bf` 复制到 PS 的 Plug-ins 目录后重启。旧测试包保留。附带示意图完全由本项目生成，不含原版参考图。

构建：`./energy/build.ps1`；旧像素回归：`./qa/run-energy-unified-regression.ps1`；最终审计／打包：`qa/verify-energy-unified.py`、`qa/package-energy-unified.py`。详细证据在 `evidence/energy-v06/`。

仅本机开发、测试与安装，**没有 Git 提交、推送或 Releases 发布**。项目自有代码采用 MIT，第三方界面库许可随包提供。旧版本的专用控制解释可参阅[电流说明](SABER_ELECTRIC_LOCAL.md)和[燃烧说明](SABER_BURNING_LOCAL.md)。
