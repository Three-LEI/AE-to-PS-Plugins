# 演示素材 / Demo assets

`demo-source.png` 来自项目维护者提供、允许用于本项目效果展示的照片；已缩放为 768×768 并移除非必要元数据。未公开原始大图、个人 PSD 或拍摄位置等元数据。

`effects/*.png` 是插件生产参数窗口及精细效果预览的实际截图，使用该照片或已注明的派生输入。截图工具复用生产界面与预览代码，独立运行，不操作个人 Photoshop 文档。窗口控件、标题和棋盘背景均来自实际界面；棋盘用于显示透明度。

`social-preview.jpg` 是 1280 × 640 的双语封面。七张示例以本项目绘制的图形为输入，由 Photoshop 中的原生滤镜实际渲染。 [封面合成脚本](../../scripts/package-cover.ps1)
