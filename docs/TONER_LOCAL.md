# Toner 多色调 0.1

多色调随 0.40 正式发布。 [下载与验证范围](RELEASE_0.40.md)

按亮度把图层颜色映射到双色调、三色调、五色调或单色。对应 After Effects 的 **CC Toner**，依据 Cycore FX HD 官方手册和本机 AE 采样独立实现，不调用 AE、Cycore 原版插件或原版二进制。

官方语义：Tones 选择双色调（Duotone）、三色调（Tritone）、五色调（Pentone）或纯色（Solid）；Highlights／Brights／Midtones／Darktones／Shadows 指定对应亮度区域的颜色；Blend w. Original 为 0% 时只显示效果，100% 时只显示原图。

## 工作方式

- 模式：双色调＝阴影→高光；三色调＝阴影→中间调→高光；五色调＝阴影→暗部→中间调→亮部→高光；纯色＝使用“高光”颜色。
- 色标位置：三色调为 0%／50%／100%，五色调为 0%／25%／50%／75%／100%；在 sRGB 数值空间线性插值。
- 亮度：`0.299 R + 0.587 G + 0.114 B`，结果限制在 0–1；HDR 高光映射到“高光”，负值映射到“阴影”。
- 混合原图：`输出 = 效果 × (1 − 混合) + 原图 × 混合`，Alpha 保持不变。
- 支持 RGB8／16／32、智能滤镜参数保存、中英文界面、蓝色单项／全部重置和公共快速预览。

本机 AE 采样核对了三色调在 0%、46.7%、100% 灰阶上的输出：分别为纯阴影色、阴影色与中间色的线性中点、纯高光色，和上述 0／50／100% 线性模型一致。

## 0.1 初版验证

- 核心 39 项检查：四种模式、色标位置、线性插值、混合方向、Alpha、HDR／负亮度及取消。
- 实际 DLL 4,739,507 项检查：RGB8／PS16／HDR32、不规则分块、平面／保护 Alpha、旧／新坐标、取消与读错误清理；另通过传统 PiPL／aete、`PluginMain` 与 UI 契约检查。
- 参数窗口截图由独立图集工具加载生产界面生成，未打开或修改个人 Photoshop 文档。
- 已在 PS2020 21.2.9 空会话实机验证：8／16／32 位普通输出与单步撤销、智能滤镜 PSD 保存、关闭后新进程重开、17 个字段恢复及 `setd` 强制重算通过。8 位撤销／智能／重开与普通输出逐像素一致，输出与预期映射最大差 1；16 位 TIFF 对照一致。32 位完成调用、描述符与重开重算，本机工具无法解码 32 位 TIFF 做像素对照。PS2026 仅安装，本轮未做完整回归。

## 安装

构建后把 `toner/build/ZaYuToner.8bf` 复制到 64 位 Photoshop 的 `Plug-ins` 目录，重启后在 **滤镜 → ZaYu-颜色校正 → Toner 多色调** 中使用。退出 Photoshop 前备份同名文件。

构建：`./build.ps1 -Module toner`，可加 `-CoreOnly`。
