# 验证与限制

**0.35-rc2：PS2020自动语言识别修复。** 当前摘要见 [validation-summary.json](validation-summary.json)。

本机Windows 11 x64（26200）＋Photoshop 2020（21.2.9）上，原生propLocale返回-30901（属性未定义），而界面首选项uiLanguageKey为zh_CN。旧逻辑在原属性不可用时默认英文；现在通过只读Basic Action Control读取interfacePrefs.uiLanguageKey。有效原属性仍优先，手动中文／English选择继续有效。

- 在真实原生参数选择阶段确认返回zh_CN，并观察实际Tint面板在“跟随PS／Auto”下显示中文；取消后临时文档关闭。
- 单元检查覆盖缺失旧回调、原属性失败、中英文、超长／无效字符串、套件获取与各读取阶段失败后的引用／描述符释放。
- 三组中文／英文／缺失语言下的手动切换、Auto恢复、重复／取消及参数不变检查通过；另有32组关于／主题／DPI检查通过。
- 十三模块完整构建及适配检查、干净导出目录native构建通过；十九份传统PiPL、六份aete的159参数、Win7依赖检查保持通过。
- 在同一PS2020中，升级前后55个效果／位深组合的113份TIFF像素相同，单步回退相同。效果内核、参数结构及原JSON元数据指纹不变。
- 本机PS2020和PS2026的十九款插件均已备份安装；临时语言诊断插件已移除。

本次实机环境是Windows 11＋PS2020，不能替代Windows 10＋PS2020和Windows 7＋PS2018的外部验证。继续发布为Pre-release。此前PS2026实机结果保留如下。

**0.35-rc1：兼容修复候选版。** 机器可读摘要见 [validation-summary.json](validation-summary.json)。

十九款改用传统二进制PiPL／aete注册，较新DPI接口改为动态检测与旧Win32回退，并采用固定ImGui HLSL的预编译SM4字节码。发行DLL不再强制导入三个Win10专属DPI接口或D3DCompiler DLL；没有改动像素内核、参数元数据和组件身份。Microsoft的[线程DPI接口要求](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-setthreaddpiawarenesscontext)说明该接口最低为Windows 10 1607；这是0.34的Win7加载阻碍之一。

- 十三模块完整构建及各自核心、实际DLL／模拟宿主检查通过；干净源码目录另外完成native模块、共享界面及传统资源构建。
- 从实际PE资源反读十九份PiPL、六份aete，对照原JSON验证中文名称、组件版本、模式、透明度／选区标志和159个术语参数。
- 十九份PE导入表中无强制Win10 DPI接口或D3DCompiler依赖。
- 中英文、四主题、两缩放共16组界面，以及强制旧DPI路径的另外16组通过。使用D3D11 WARP验证固定着色器、链接和窗口行为。
- 明确在Photoshop 2026（27.7.0）执行55个效果／位深组合，113份TIFF与已安装0.34的像素相同，并验证单步回退。

**旧环境实机结果待补充**：Win7＋PS2018、Win10＋PS2020尚不能写作已验证支持；在现代系统强制旧DPI分支不能替代真正旧系统测试。当前包标为Pre-release，需在反馈出问题的两台机器上复测菜单、面板、预览和应用。未附加外部参考层刷新脚本。

以下保留0.34已完成的验证范围。

**0.34：以下检查已通过。** 机器可读摘要见 [validation-summary.json](validation-summary.json)。

0.34 的改变为开源目录与构建配置、共用蓝色“开源地址”及默认浏览器跳转。生成内核、参数结构、组件身份和滤镜版本保持0.33。

本次验证流程：

- 从0.33已安装的十九款插件记录RGB8/16/32基线：Tint仅RGB8，共55个效果／位深组合，保存效果和单步回退像素。
- 完整构建十三个模块，运行各自核心、DLL／模拟宿主适配和必要共用检查。
- 关于链接覆盖中文／英文、四种主题和100%／200%缩放，共16组。验证蓝色无边框链接的URL、点击成功／失败分支、关闭／Esc、参数不变，以及Photoshop关于增效工具入口。自动测试截获链接请求，不会反复启动浏览器。
- 重建后重复55个PS实机组合，比较113份TIFF的实际像素字节并验证单步回退。
- 使用独立干净源码目录验证完整构建，避免依赖历史下载目录或构建中间文件。
- 发布审查核对十九款清单、URL、固定ImGui源码指纹、相对包含闭包，排除SDK、字体、二进制、凭据和原本机路径。编译期路径映射用于避免将工作目录写入断言信息。

实际宿主版本为Photoshop 2026（27.7.0），仅验证Windows x64。上述限定样例相同不代表任意图像、其它PS版本或所有AE参考都已覆盖。

此前的效果开发以自制参考核对公开参数与输出：光学补偿／镜头69组、Glass／Blobbylize72组、湍流／扫光／万花筒81组、毛边115组；这些属于独立近似校准，不是任意图像与原版逐像素一致的承诺。原始历史截图、PSD及AE工程留在本地研究区，不随源码上传。

每个模块README记录各自边界。尤其注意：Tint仅支持RGB8；部分完整源图上限16,777,216像素；透明度保护和背景层受PS宿主限制；几何效果不自动扩展画布；独立随机晶格不保证与AE同种子形态一致；Glass／Blobbylize外部参考层需手动重开更新；早期效果的智能滤镜保存能力以对应模块说明为准。
