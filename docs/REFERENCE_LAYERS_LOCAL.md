# 完整参考图层 · 0.39 收录

应用到目标层的选区仍由 Photoshop 控制输出范围。参考层用自己的 RGB 和 Alpha 边界读取，保留其在文档中的位置，包括画布外仍存在的内容。要只引用某个区域，可先用选区把那块纹理复制到单独图层，再选择新图层。

焦散、Glass、Blobbylize、Glow、Deep Glow、Chromatic Dispersion、Vector Blur、JPEG Damage、Lens Flare 和 Displacement Map 的预览与应用共用此读取规则。遮罩仍按文档坐标对齐；参考层以外是透明空白。置换贴图继续按「居中／拉伸／平铺」设置使用自己的完整贴图；焦散也保留边界模式。因此原来依赖画布裁切或空白边缘循环的外部参考，重算时可能会得到不同画面。

参考层修改后，已有智能滤镜仍需重新进入以刷新。超大参考层沿用原生读取的单张 16,777,216 像素上限；仅能读取 Photoshop 向插件提供的通道内容。
