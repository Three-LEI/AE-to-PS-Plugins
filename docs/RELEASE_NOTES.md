0.36-rc1 · 全部智能滤镜参数保存与界面修复

- 十九款效果完整参数随智能滤镜保存到PSD。补齐分形杂色、色差色散等前十三款的描述符字段，原六款保留既有保存格式，统一复用资源管理和提交层。各实例分别保存，参考层使用Unicode唯一名称关联。
- 按文档实际图层名构建所需字体字形，修复“鎏金”等少见汉字显示问号；兼容旧宿主提供的UTF-8图层名称。
- 单项重置改为圆弧箭头，保留蓝色无边框样式；参数旁仅重置该项，底部“全部重置”恢复全部默认参数。
- 保留0.35-rc2的传统PiPL／aete注册、旧系统DPI回退、固定SM4界面着色器和PS2020自动语言识别。生成内核、默认参数、参数结构及组件身份保持不变。

在本机Win11＋PS2020（21.2.9）完成55组效果／位深、110个非默认实例的PSD保存、退出PS后重开及强制重算；110次像素比较一致。另有十二份旧PSD的54个实例参数保留，113份常规导出与rc2像素一致；共用保存层8642项检查、十三模块构建及字体／重置／旧DPI检查通过。

用户已确认rc2支持Win7＋PS2018（19.1.6）及Win10＋PS2020（21.2.3）。本次候选版仍请在这两台机器复测，继续发布为Pre-release；历史发行保留以便回溯。具体范围见仓库docs/VALIDATION.md。

请退出PS、备份旧插件并替换同名.8bf，避免多个插件目录存在重复副本。需要可编辑参数时，请先将目标层转为智能对象；旧文件中此前没有保存的参数不能追溯恢复。外部参考层内容变化仍需手动重开效果确认更新，无需刷新脚本。

系统和PS均需64位，普通使用无需AE、SDK或Python。
