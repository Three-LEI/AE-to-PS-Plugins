0.35-rc2 · PS2020 自动语言识别修复

针对中文PS2020中插件界面自动显示英文的问题：旧宿主的原生propLocale属性会返回“属性不存在”。现在该属性不可用时，通过只读Basic Action Control读取interfacePrefs.uiLanguageKey，自动跟随PS实际界面语言。有效的原属性仍优先，手动中文／English选择保持有效。

- 十九款统一更新共享语言读取代码，效果内核、默认参数、组件身份和参数结构不变。
- 保留rc1的传统PiPL／aete注册、旧系统DPI回退和预编译界面着色器。
- 原生读取诊断确认PS2020（21.2.9）的原属性返回-30901，其界面语言首选项为zh_CN。
- 单元检查覆盖中英文、旧属性失败、缺失回调、无效／超长语言值，以及套件和描述符在错误分支的释放。

本机Windows 11＋PS2020（21.2.9）已确认Auto实际显示中文；55组效果／位深、113份导出与rc1像素一致。十三模块构建、32组共用界面和三组语言切换检查通过。完整范围见仓库docs/VALIDATION.md。Win7＋PS2018仍待用户实机复测，因此继续提供为Pre-release。

退出PS并备份旧插件，替换同名.8bf后重新启动。系统和PS均需64位；避免多个插件目录中的重复副本。普通使用无需AE、SDK、Python或额外刷新脚本。
