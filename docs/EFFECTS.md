# 效果列表

0.40 包含 **41 款 Windows x64 原生滤镜**，分布在 33 个模块。第 32–41 款为本次新增，见 [0.40 发行说明](RELEASE_0.40.md)。

<a id="本机菜单分组"></a>

## 菜单分组

直属复刻依据 [Adobe After Effects 效果列表](https://helpx.adobe.com/cn/after-effects/desktop/apply-effects-and-animation-presets/effects-and-animation-presets/effect-list.html)归类。第三方效果按用途放到最接近的 AE 分类，例如长投影随投影类归入「透视」。

| 菜单 | 数量 | 效果 |
| --- | ---: | --- |
| ZaYu-颜色校正 | 2 | Tint、Toner |
| ZaYu-扭曲 | 7 | Displacement Map、Chromatic Dispersion、Optics Compensation、Lens、Blobbylize、Turbulent Displace、Mirror |
| ZaYu-风格化 | 12 | Glow、Deep Glow、Starglow、Glass、Kaleida、Roughen Edges、Halftone、ASCII Dither、Dither、Etching、RepeTile、Pixel Sort |
| ZaYu-生成 | 7 | Grid、Checkerboard、Cell Pattern、Light Sweep、Shine、Saber、Lens Flare |
| ZaYu-杂色和颗粒 | 4 | Fractal Noise、JPEG Damage、Film Damage、Noise |
| ZaYu-模糊和锐化 | 3 | Vector Blur、Channel Blur、Compound Blur |
| ZaYu-透视 | 3 | Long Shadow、Sphere、Cylinder |
| ZaYu-模拟 | 2 | Caustics、Rain & Snow |
| ZaYu-过渡 | 1 | Venetian Blinds |
