本轮为本地测试候选，未提交 GitHub，也未发布 Releases。原有 19 款接入公共快速预览；Starglow／Shine 延续已验证的交互预览流程。Shine 的已安装二进制保持不变。

## 使用

“交互快速预览”默认开启。连续调整参数时先显示最长边约 256 像素的草图；停止变化约 180 毫秒后，自动恢复该插件原有的精细预览路径。界面标记“快速／精细”。可取消勾选，直接等待精细结果。

精细预览的范围和精度沿用各插件原有设计：有些处理完整源图，有些处理当前视口的宿主代理图。点击确定后，一律使用原始参数和原有完整输出路径，草图不写入图层或 PSD。快速预览开关是窗口状态，不加入智能滤镜参数。

缩图可能暂时弱化细纹、细小透明边缘、JPEG 方块和微小高光。判断最终细节时等待“精细”，或关闭交互快速预览。首次读取源图／外部参考层仍由 Photoshop 主线程完成，可能需要等待；此版本没有增加 GPU 效果计算。

## Starglow 改进

参考 [Maxon 官方 Starglow 说明](https://help.maxon.net/rg/en-us/Content/html/01-Starglow-trapcode-starglow.html)及其官方示例，保持“从输入高光产生最多八个方向光刺”的定位。

- 光刺不再逐方向重复叠加当前位置的高光，减少中心烧白。
- 长度与近端亮度解耦；阈值后的高光保留可用强度。
- 任意角度采用剪切扫描，避免沿途重复插值造成光刺越来越糊。按图像有效范围裁剪扫描，兼顾狭长图性能。
- 仅对生成的星芒做柔和亮度限制，避免大块亮色累积成一片白；原图 HDR 数值不受此限制。
- 新建效果的默认长度随素材大小适当变化；已保存的显式参数不变。

动漫图可先用“十字星”预设，将阈值提高至约 0.85～0.95、柔和度降至约 0.03～0.08，再调长度和光照增强。大块高光会产生较宽光刺，小而集中的高光更接近示例中的闪亮星形。这些数值是起点，取决于原图亮度。没有添加随机星粒；独立实现尚未完成原版同源图逐像素校准。

## 开发接入

公共接口：`native/ui/include/psui/adaptive_preview.hpp`，调度基础：`coalesced_preview.hpp`。

1. 以 `AdaptivePreview<Result>` 提交冻结的参数与源数据。普通参数变化只提交新任务，避免停止并等待工作线程；进行中的草图允许完成，排队请求合并到最新一次，过期精细任务可取消。
2. 空间滤镜使用 `DraftImageCache` 与 `PreviewSpace`，对源图和参考层使用同一文档坐标网格，按 Alpha 加权缩小；仅在参数副本中换算像素单位与绝对中心点。完整预览直接使用原图、原参数。
3. 区域生成器／宿主代理图使用保留原生坐标的 Region 和独立快／精细快照。宿主读取、选区读取、纹理上传均留在界面线程，后台只做 CPU 计算。
4. 外部参考快照改变前停止工作并清空缓存，窗口退出前结束后台任务。不要把交互草图状态加入参数存储协议。
5. 用 `worker.controls` 提供公共开关和状态。新增效果须验证持续拖动能出帧、停止后精细更新、取消不写回参数，以及完整输出与优化前相同。

## 验证与兼容

证据见 `evidence/adaptive-preview-v01/qa.json`、任务记录和各日志。PS2020 21.2.9 实机验证了全部 21 款；原有 19 款＋Shine 的 58 组位深输出与基线逐像素一致，原有 26 个核心／参数头文件不变。全部效果的智能滤镜均完成实际新进程重开 PSD 与强制重算验证。

保留传统 PiPL／aete、旧系统 DPI 回退、预编译 UI 着色器及原参数协议。二进制审计未引入列出的新系统强制 API；仍需用户在 Win7＋PS2018 和外部 Win10＋PS2020 上复测，本轮不将这些外机环境记为已验证。
