# 操作按钮加高（本地测试）

全部 22 款滤镜共用的普通操作按钮改为至少 **26 个逻辑像素**高，随 DPI 缩放；例如 200% 时为 52 像素。字体需要更高空间时仍以字体高度为准。包括确定、取消、全部重置、更新路径等使用公共按钮的操作。蓝色单参数重置图标和数值参数行保持原尺寸。

底部三按钮的预留空间使用实际按钮高度计算，避免只改按钮造成遮挡。保持现有窗口尺寸；预览根据剩余空间调整，右侧参数区继续滚动。Tint 的右侧底部布局和 Fractal Noise 的固定底部区域也纳入布局验证。

Fit／适合按钮与前面的缩放数值框垂直居中对齐。“正在计算”改为预览区域左上角的浮动文字，出现、消失都不占布局空间，下面的介绍文字保持定位。白色文字使用差值混合，补充细暗描边以改善中灰色背景的辨识度。

浮动提示只增加少量文字绘制，着色器和混合状态按窗口缓存；不读取预览像素，不参与滤镜计算。使用预编译 SM4 字节码，无新增运行时 D3DCompiler 依赖。四种背景的 GPU 像素公式与忙碌／空闲布局位置均有独立验证；不支持该绘制状态时退回带暗描边的白字。

沿用传统 PiPL／aete、旧 DPI 回退和预编译界面着色器，不增加新系统强制接口。不修改其他滤镜的生成内核、参数字段及保存格式；Saber 本轮另增加 12 个参数预设，见 [预设说明](SABER_PRESETS_LOCAL.md)。

本机测试证据在 `evidence/ui-buttons-v01/`；本轮整包为 `dist/AEPS-Local-UIButtons-Saber-0.7.zip`。退出 Photoshop、备份后覆盖同名 `.8bf`，避免多个插件目录留有重复副本。本机 PS2020／PS2026 已备份更新；PS2026 27.7.0 完成完整保存／新进程重开测试，PS2020 21.2.9 完成加载及保存重开简测，旧机仍需复测。仅本机开发测试，不提交 GitHub 或发布 Releases。
