# Long Shadow 长投影 0.3

根据图层的透明度轮廓沿指定方向生成连续阴影。可以给文字、图标、标志、形状或抠图做平面长影；独立实现，参考 [Maxon Universe Long Shadow](https://help.maxon.net/uni/en-us/Content/html/long-shadow.html)，不需要 AE 或原版。

1. 在有透明区域的图层上使用。文字或形状建议先转换为智能对象，再打开「滤镜 → ZaYu-透视 → Long Shadow 长投影」。
2. 用方向、长度、颜色、不透明度和扩张控制阴影。0° 向右，90° 向下，45° 向右下。尾部渐隐 0% 为实边长影，调高后向末端渐淡。
3. 「源裁切」按主体的左右范围只让一部分形状投影，保留原主体；「投影遮罩」用矩形或椭圆限制阴影写入的区域，可移动、缩放、羽化与反转。
4. 勾选「仅输出阴影」可单独排版。可以复制原层，把阴影版放到原层下。

「颜色模式 → 拉伸源颜色」沿投影方向延续源图本身的颜色，用「源色明暗」调整投影亮度。100% 保持源色；60%–80% 可让彩色长影更像阴影。对透明区域的颜色按有效 Alpha 取样，保留 HDR 高光。

「起始间距」将阴影沿方向移开。「近端模糊」「远端模糊」相同会得到均匀柔边；把远端设得更大，能模拟接触处较清晰、远处半影较宽的软阴影。模糊只影响阴影，尾部渐隐另管透明度。悬浮效果可从间距 12 px、近端 1.5 px、远端 18 px 开始，或选「悬浮软影」预设。默认纯色、间距 0、两端模糊均为 0，0.1 的 PSD 重算保持原画面。

近端和远端都可输入 0–160 px。0.3 修正两端差值较大时阴影内部出现的弧形接缝。PSD 参数保持不变；渐变模糊重新计算后使用修正后的过渡，硬边和均匀模糊的输出不变。

普通像素层的投影可进入原轮廓外的透明区域，最终仍受 Photoshop 给出的处理范围约束。图层有选区时只写选区；锁定透明像素会限制投影的扩张。若智能对象边界裁掉长影，可给它的源文档增加透明留白。打开智能对象内容后仍可编辑原文字；保存内容可触发重算。RGB8／16／32。支持项目的中英文界面、参数重置、自适应预览与智能滤镜参数保存。

安装：退出 Photoshop，把 `ZaYuLongShadow.8bf` 复制到 64 位 Photoshop 的 `Plug-ins` 并重启。本机 PS2020 21.2.9 实测，PS2026 仅安装，Win7／CC2018 尚未实机复测。第 31 款效果，已随 0.39 发布。

### 关于图层样式

Adobe 公开的 [Photoshop C++ SDK](https://github.com/AdobeDocs/photoshop-cpp-sdk) 可注册滤镜；公开接口中没有将第三方渲染器注册为「图层样式 → fx」新条目的入口。Adobe 的 [UXP batchPlay](https://developer.adobe.com/photoshop/uxp/2022/ps_reference/media/batchplay/) 可执行现有 Photoshop 命令，包括应用已有样式；[样式预设](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/manage-preset-styles.html)可以保存原生效果的组合与参数。长投影以智能滤镜保存自有算法与参数。
