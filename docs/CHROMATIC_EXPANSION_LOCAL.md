# 色差色散模式扩展 · 0.9 本地测试版

继续使用同一个 **Chromatic Dispersion 色差色散** 插件，没有增加独立滤镜。项目仍共21款，本轮只替换色差色散，其余20款文件保持不变。未提交GitHub，也未发布Releases。

## 新模式

在“模式”中保留原有 RGB 分离、连续光谱，追加以下两项：

**光谱变换 / Spectral Transform**

红端和蓝端各有独立的缩放、旋转、X／Y位移，中间光谱平滑过渡。变换强度控制整体幅度；原有光谱采样、色相、饱和度、柔和度、中心、中心保护和高光筛选可继续使用。用左键拖动预览中的中心手柄可设置位置。遮罩在这个模式中调节变换幅度，使灰色遮罩处产生中间变形。

**棱镜散焦 / Prism Defocus**

提供实际的环形／实心光圈滤波，支持圆形、三角形至八边形，共7种形状。可调整散焦半径、环宽、光圈旋转、长宽比、圆润度，以及红／绿／蓝相对半径。环宽100%为实心光圈；环宽较小时为中空色环。RGB半径相同可得到普通光圈散焦，半径不同可产生彩色光环。此模式的遮罩沿用结果混合方式。

散焦质量提供快速／标准／精细。大半径使用该档位对应的多分辨率工作图计算，再输出原始尺寸；精细档更适合观察细色环。此设置会保存到PSD，属于效果计算质量；“交互快速预览”则是拖动时临时降低预览分辨率，停止约180毫秒后恢复该质量档位的精细预览。

## 新预设

- 光谱缩放：红蓝两端使用不同缩放。
- 光谱旋转：红蓝两端使用相反方向的旋转。
- 棱镜光环：中空的多色圆环。
- 六边形散景：带轻微色边的实心六边形光圈。

`预设示意.png` 从左到右对应以上4个预设，使用同一张自制点线素材。旧4个预设及默认连续光谱设置保持不变。普通照片如需减少画布边缘变暗，可把边缘处理设为“延伸”；处理散景高光时也可以启用“仅处理高光”。

## 参数与旧文件

原RGB／连续光谱保持独立的原算法路径。24组旧模式案例与旧内核逐字节一致；PS2020中，原0.8版本保存的PSD在新版中参数、重开及强制重算像素一致。

保留原有45个效果字段的ID、效果事件及身份，新增19个字段，共64项效果参数，另有版本和身份字段。旧内存参数块会自动迁移，新字段采用默认值。新模式的PSD需要本扩展版或更新版本；旧0.8版本不具备这些模式。

新增参数沿用蓝色单项重置；“全部重置”仍恢复原插件默认的连续光谱。完整参数可随智能滤镜保存，普通像素层直接应用仍只得到像素结果。

## 安装与验证

退出Photoshop，备份原`ZaYuChromaticDispersion.8bf`，将补丁内同名文件覆盖到插件目录，重启后加载。其余插件无需覆盖。

已安装本机PS2020／PS2026；本轮PS2020 21.2.9完成实机验证，PS2026仅安装。保留原有传统PiPL／aete和旧DPI回退，二进制没有新增强制导入函数或DLL。Win7＋PS2018、外部Win10＋PS2020仍待用户复测。

验证包含：旧／新PSD共12个实例，12组新预设／位深输出和撤销，473815项扩展核心断言，13002项共用参数协议检查，24组旧模式逐字节一致、8组新模式串行／并行一致，以及6组新旧界面检查。新模式连续约42帧拖动得到40个新预览帧，停止后精细更新、单项重置、取消及中文字体检查通过。

光谱仍为基于RGB的艺术近似；光谱变换和光圈核均为独立实现，不承诺与Sapphire逐像素一致。功能参考：[WarpChroma](https://borisfx.com/documentation/sapphire/ae/warpchroma/)、[DefocusPrism](https://borisfx.com/documentation/sapphire/ae/defocusprism/)。测试证据见`evidence/chromatic-v02/qa.json`及任务记录。
