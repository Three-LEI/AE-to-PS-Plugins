# 计算与预览性能

0.37 合并了本地 0.9 的性能与预览改进，23 款的整包程序与该已验证候选相同。**生成使用 CPU，GPU 用于界面与预览显示。**

## 已实现

- 预览工作线程在窗口内复用计算线程；多阶段最终生成在单次渲染内复用。完成通知立即唤醒调用方，取消回调留在调用线程，各任务继承浮点环境。关闭窗口或完成生成后回收线程，DLL 静态对象不持有活动线程。
- Glow／Deep Glow 的模糊遍数复用临时输出和前缀和缓冲，保持原有公式及处理步骤。
- 公共有界阶段缓存首先用于 Glow／Deep Glow：非零曝光、着色等合成参数变化时复用前置提取与模糊；半径、阈值、伽马、遮罩及相关计算条件变化时重建。滤色／相加、源视图和零曝光分别处理。
- 每个发光窗口最多保留两组、合计 96 MiB 的图像缓存，超限时直接计算。取消的结果不进入缓存，输入重读及关闭窗口时释放缓存。缓存不写入 PSD，最终宿主输出仍直接按原图和原参数计算。

## 平衡预览画质

草图初始最长边为 512，按耗时在 256／384／512／768 间调整；停止参数变化约 180ms 后回到精细预览。透明区域采用预乘 Alpha 采样。

百叶窗草图只计算条纹遮罩，再作用于原图，避免照片与细文字随草图一起模糊。六组合成样例中，平均预乘 RGB 误差较旧固定 256 草图下降约 80.8%；这不是所有素材的画质提升比例。

## 测量

下表为本机自有合成图的 CPU 核心耗时，预热后取三次中位数，不包含 Photoshop 图层读取、界面显示或文件保存。比较对象为本轮性能优化前的本地候选；不是对 0.36-rc1 或 AE 原版进行速度比较。

| 512×384 输入 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 带羽化的百叶窗 | 85.3ms | 4.1ms |
| Glass | 88.0ms | 5.8ms |
| Saber 基础公共流程 | 339.4ms | 22.6ms |
| Shine | 66.7ms | 12.8ms |
| Deep Glow 直接完整计算 | 282.2ms | 256.3ms |

同一测试进程中，Deep Glow **768×512、半径 100** 的连续非零曝光调整，平均每次直接计算约 **351.3ms**，命中准备缓存后约 **19.5ms**，图像缓存占 12 MiB。首次计算与改变半径等前置参数仍需重新准备。

素材、参数、系统计时精度及硬件都会影响收益，不承诺固定加速倍数。36 组完整浮点图像与性能优化前逐字节一致，396 组缓存／直接输出对照及冻结内核的参数变体验证通过。完整验证范围见 [VALIDATION.md](VALIDATION.md)。
