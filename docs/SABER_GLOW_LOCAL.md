# Saber 0.3：基础分层发光（本地测试）

当前本地版本为 [0.6 公共参数版](SABER_UNIFIED_LOCAL.md)，新建效果固定使用公共分层发光，不再提供样式／发光模型切换。下文为 0.3 历史说明，分层发光的参数含义继续适用；旧 PSD 可保留旧流程或明确转换。

本阶段（0.3）针对原版 Saber Default 的圆环和直线，改进基础光核、贴近光核的亮边和宽阔光晕。后续电流与燃烧形态已分别在 0.4／0.5 扩展；下文保留基础发光控制说明。本项目独立编写，不是原版插件的移植或逐像素替代。

新建滤镜默认使用 **分层发光**；旧 0.1／0.2 PSD 自动保留 **经典模型**，不会因安装更新而改变旧生成结果。可以在“发光 → 发光模型”手动切换；“全部重置”恢复当前 0.3 的新建默认值，并清除路径快照。两点、钢笔路径、Alpha 轮廓和笔画的用法继续见 [输入与保存说明](SABER_LOCAL.md)。

## 使用与参数

新建 RGB 文档，画细线／使用钢笔路径／准备有透明背景的文字或 Logo，然后打开“滤镜 → ZaYu-AE 效果复刻 → Saber 能量光束”。先用“蓝色光束”预设检查基础光核和光晕，再调整颜色、宽度与强度。图层完全不透明时，“Alpha 轮廓”会描出画布边框。

| 控制 | 用途 |
| --- | --- |
| 核心宽度、亮度、核心白度 | 调整实心光核及整体能量；笔画输入仍使用源 Alpha 的宽度。 |
| 光晕半径、光晕强度 | 控制四档远近光晕的总体范围和强度。半径为像素尺度，不是光晕的硬裁切边界。 |
| 近光强度、近光半径 | 单独调整贴近光核的较亮光晕。它独立于上面的四档光晕。 |
| 发光预伽马 | 调整发光种子中较弱的透明覆盖；大于 1 时更容易带起较弱区域，不改变源图颜色。 |
| 近光偏重 | 增大时加强范围比小于 1 的光晕档位，改变近处与远处的强弱关系。 |
| 发光分层设置 | 展开后可分别设置远／中／近／细四档的范围比与强度。范围比乘以总体光晕半径；范围比或该档强度为 0 时关闭该档。 |

只关闭“光晕强度”仍会保留近光；只看光核时，将“光晕强度”和“近光强度”都设为 0。参数旁的蓝色箭头重置对应参数，左下角“全部重置”恢复全部。拖动时自动降低预览分辨率，停止后恢复精细结果，保存的参数和最终输出分辨率不受影响。

新默认值以 384×384 对照图校准，光核宽度为 6px、总体光晕半径为 184.2px、近光半径为 10px。其他分辨率可按画面调整；**这些是本项目的像素参数，不与原版同名数值直接对应**。原版公开参数与本地研究记录见 [材质研究](SABER_MATERIAL_REVIEW.md)。

## PSD 与版本

48 个效果字段、Unicode 路径名及路径几何快照均可保存。新分层模型使用保存格式 3；旧模型继续使用格式 1／2。0.1／0.2 插件会拒绝读取格式 3，避免把新效果静默变成旧效果，因此使用新模型的 PSD 需要 0.3 或更新版本。

已有 PSD 默认保持经典模型。想在旧效果上体验新光晕时，先手动切换发光模型，再按需调大光晕半径；保留旧参数意味着切换后不会自动套用新预设。Alpha 输入跟随智能对象自身内容更新；外部钢笔路径仍使用保存快照，编辑外部路径后需重新进入滤镜更新路径。

## 验证与限制

- 0.1 基础效果 24 组、0.2 输入／材质 24 组冻结样例逐像素一致；新模型的串行与并行结果一致。
- 本机 PS2020 **21.2.9** 验证 RGB8／16／32、独立智能滤镜实例、保存、重启后重开与强制重算，以及旧 PSD。完整结果在 `evidence/energy-v03/qa.json`。
- 中英文界面、中文 200%／旧 DPI 回退、拖动快速帧、松手精细更新和单项重置通过。其他 21 款滤镜二进制保持不变。
- PS2026 **27.7.0** 本轮仅安装。沿用传统 PiPL、旧接口与 DPI 回退；**Win7＋PS2018 19.1.6、其他 Win10＋PS2020 21.2.3 仍需外机复测**。
- 原版参考工程使用 Working Space=None、未线性化，输出为 8 位 TIFF。本阶段校准的是这种显示条件下的默认蓝色基础发光；不代表所有颜色、HDR、材质和色彩管理设置都已匹配。没有相似度百分比声明。
- 图层／画布／选区仍会裁切超出范围的光晕。坐标转换和路径复杂度限制沿用 0.2。

## 安装与开发

`dist/AEPS-Saber-local-0.3.zip` 只包含一个滤镜二进制。退出 PS，备份旧同名文件，将包内 `Plug-ins/ZaYuSaber.8bf` 覆盖到 PS 的 Plug-ins 目录，然后重启。旧 0.1／0.2 测试包保留供回溯；不需要覆盖其他滤镜。

本机 PS2020／PS2026 的原有 Saber 已单独备份到 `evidence/energy-v03/installed-before/`。新版本仅本机开发测试，**没有 Git 提交、推送或 Releases 发布**。

构建：`./energy/build.ps1`；冻结效果回归：`./qa/run-energy-glow-regression.ps1`；原版对照、自动测试与打包脚本见 `qa/*energy-glow*`。许可为 MIT，仅包含本项目实现和所用界面库的许可证，不打包原版插件、私有预设或原版参考图。
