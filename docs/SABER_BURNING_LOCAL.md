# Saber 0.5：路径燃烧（本地测试）

当前本地版本为 [0.6 公共参数版](SABER_UNIFIED_LOCAL.md)，燃烧改为同一公共流程的参数预设。下文为 0.5 专用样式的历史说明；旧 PSD 保留原流程，可明确转换。

新增 **“燃烧 / Burning”** 样式及同名预设。焰体围绕路径分布，带局部卷曲和细碎焰丝；默认无风，可另外设置风力和风向。原来的向上火焰保留为 **“经典火焰”**，旧 PSD 的生成行为保持不变。

**新建滤镜仍默认基础光束。体验本阶段材质时，在“材质预设”选择最后一项“燃烧”。** 电流光晕继续保留，使用见 [电流说明](SABER_ELECTRIC_LOCAL.md)。

原版 Saber Burning 的同圆环输出用于观察结构和暖光分布；本项目独立实现，参数、随机形态和颜色处理未逐项对齐，不声明逐像素一致或复刻百分比。

## 调整方式

两点、钢笔路径、Alpha 轮廓和 Alpha 笔画均可使用。文字／Logo 想沿透明边缘燃烧时选 Alpha 轮廓，已有细线可选 Alpha 笔画；笔画模式保留整个原始 Alpha 覆盖，粗形状较容易变亮，可降低亮度与焰体强度。完全不透明的图层会沿画布外框描边，详见 [输入说明](SABER_LOCAL.md)。

| 控制 | 用途 |
| --- | --- |
| 焰体厚度 | 控制周围火光的范围；设为 0 后仍保留光核与普通发光。 |
| 卷曲幅度 | 调整焰体的弯折和起伏；设为 0 仍有强弱不均的火纹。 |
| 火纹尺度、燃烧细节 | 改变纹理的疏密和层次。 |
| 焰体强度 | 调整新增焰体整体能量；为 0 时只剩光核和普通发光。 |
| 焰丝强度 | 调整细碎亮线部分，为 0 可只看较柔软的焰体。 |
| 燃烧种子、燃烧演化偏移 | 选择焰体形态，不移动基础路径。 |
| 外焰颜色 | 调整较冷、较弱的外围火光颜色；靠近热区时向主光束颜色过渡。 |
| 风力、风向 | 推动周围焰体；风力为 0 时没有方向偏移，光核保持在路径上。 |
| 光核畸变 | 调整亮芯起伏，开放路径的光核端点保持连接。 |

“核心”可设置主颜色、亮度和白度；“发光”继续提供近光、四档光晕与预伽马，见 [发光说明](SABER_GLOW_LOCAL.md)。关闭光晕强度并不会关闭直接可见的焰体；只看光核时，还需关闭焰体强度和近光强度。

“随机与演化”中的种子控制光核，整体演化同时推进光核与焰体；燃烧组的种子／演化偏移可单独选择焰体。改变轮廓、修剪、宽度或 Alpha 阈值仍会同时改变它们的基础形状。

参数旁的蓝色箭头重置对应参数；“全部重置”回到当前新建默认的基础光束并清除路径快照。可重新选择“燃烧”预设恢复该预设。拖动时沿用公共快速预览，停止后精细更新；细小火纹会在精细更新时补足。

## 保存与兼容

共 **66 个效果字段**，原 57 字段 ID 保持不变，另保存 Unicode 路径名与几何快照。新燃烧使用保存格式 5，需要 **0.5 或更新版本**。旧 0.1／0.2／0.3／0.4 PSD 保留原样式和发光模型，不自动升级外观；旧火焰与新燃烧可分别选择。

Alpha 跟随智能对象自身内容更新。外部钢笔路径仍使用快照，修改后需重新进入滤镜更新路径。图层、画布和选区会裁切越界光晕；变换智能对象的坐标限制沿用原有输入说明。

本机 PS2020 **21.2.9** 验证 RGB8／16／32、保存、重开和强制重算，以及旧 0.4 PSD 回放。0.1／0.2／0.3／0.4 共 96 组冻结像素样例保持一致；中英文、中文 200%／旧 DPI 回退、拖动更新、松手精细与单项重置通过。汇总见 `evidence/energy-v05/qa.json`。

PS2026 **27.7.0** 本轮仅安装。沿用旧接口、传统 PiPL 和 DPI 回退；**Win7＋PS2018 19.1.6、其他 Win10＋PS2020 21.2.3 仍待外机复测**。其他 21 款滤镜二进制保持不变。
