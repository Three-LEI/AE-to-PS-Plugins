# Venetian Blinds 百叶窗 0.1（本地测试）

用平行透明条带隐藏当前图层，适合图文切片、条纹镂空、遮挡和静态转场画面。[Adobe 对百叶窗的说明](https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/transition-effects.html)描述了这种按方向与宽度露出下层的效果；本项目为独立 CPU 实现。

## 使用

1. 需要保留可编辑参数时，先把目标层转换为智能对象。
2. 打开“滤镜 → ZaYu-AE 效果复刻 → Venetian Blinds 百叶窗”。
3. 默认完成度为 0%，保留原图。调为 50% 或选择半开预设，即可看到条带。
4. 用“显示背景”检查下方图层的近似合成，或在透明棋盘上检查间隙；该开关只影响预览。
5. 确定后保存 PSD，之后双击对应智能滤镜继续编辑。

| 参数 | 含义 |
| --- | --- |
| 过渡完成 | 0% 保留原图，100% 完全隐藏；中间值控制隐藏比例。 |
| 方向 | 0° 为竖向条纹，90° 为横向条纹，支持斜向和旋转多圈。 |
| 宽度 | 条纹重复周期，以原始像素为单位；范围 1～32000。 |
| 羽化 | 柔化条纹边缘；范围 0～32000。 |
| 位置 → 条纹中心 | 控制条纹起始位置。默认位于输入画面中心；“中心居中”恢复居中。 |

四个预设为半开竖向、半开横向、斜向柔边和细密条纹，套用时保留条纹中心。手动修改参数后显示为自定义。单项蓝色箭头恢复对应参数，全部重置恢复 0% 完成度和居中位置。

## 图层与透明度

普通图层或智能对象可以生成真实透明间隙。锁定的背景层没有可写透明度，会把间隙合成到黑色；锁定透明度时不能隐藏像素。需要露出下面图层时，请先转换为普通图层或智能对象，并解除透明度锁定。

本效果保持源 RGB 数值，只减少 Alpha；原有透明孔洞保持透明，HDR 颜色不会因条纹遮罩而被额外截断。像素图层直接应用只保留栅格结果，可编辑参数需通过智能滤镜保存。

条纹中心随参数保存为绝对像素坐标。改变画布大小后，可重新使用“中心居中”；不会自动重定位已有实例。选区及滤镜蒙版由 Photoshop 处理。完整输入限制为约 1677 万像素，与同类缓存式效果一致。

## 预览与保存

沿用公共快速预览：拖动时降低分辨率，停止后恢复精细结果，最终处理使用原尺寸。操作按钮加高、Fit 居中和预览内浮动计算提示均沿用本轮公共界面；预览状态和缩放不写入参数。

6 个效果字段（四个核心参数＋中心 X／Y）使用共用描述符保存层，保存格式为 1；新增独立组件与事件，不占用其他滤镜的参数身份。每个智能滤镜实例独立保存，不依赖上次使用值或外部脚本。智能对象自身内容变化后，PS 会重算条纹。

## 对照与兼容

已用本机 AE2025 25.6.5x3 的原生百叶窗生成 16 个同参数白色输入参考，覆盖完成度端点、方向、分数宽度及大小羽化。Alpha 平均误差在这些固定样例中不超过约 2.06/255，边缘单像素最大误差约 16.44/255。羽化为独立拟合的近似，不保证原版内核、所有参数或任意素材逐像素一致；该对照不代表 RGB/HDR 全空间校准。

PS 版支持 RGB8／16／32。原版文档列出的百叶窗支持 8／16 位；本项目的 32 位支持为扩展，不宣称与原版 32 位效果等效。详细证据在 `evidence/blinds-v01/`。

本机 PS2020 21.2.9 已验证 18 组普通输出与 CPU 参考、撤销、36 个智能滤镜实例在新进程恢复、36 次重开／强制重算图像比较，以及源内容更新和恢复。中英文、中文 200%／旧 DPI 回退、连续快速帧与停止后精细更新检查通过。PS2026 本轮仅安装。

用户已确认上一轮 0.7 本地整包可在 Win7＋CC2018 运行。新百叶窗沿用传统 PiPL／aete、旧接口、DPI 回退及预编译界面着色器，但**本款仍需单独在 Win7＋PS2018 和外部 Win10＋PS2020 复测**。

## 安装

本地包 `dist/AEPS-VenetianBlinds-local-0.1.zip` 只包含新百叶窗。关闭 PS，把 `Plug-ins/ZaYuVenetianBlinds.8bf` 复制到 PS 的 Plug-ins 目录后重启。现有 22 款二进制保持不变，旧测试包保留。
