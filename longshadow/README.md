# Long Shadow 长投影

按 Alpha 将文字、形状或抠图投射成连续长影。支持纯色／拉伸源色、源色明暗、起始间距、近端／远端模糊、尾部渐隐、扩张、源裁切、矩形／椭圆遮罩和单独输出阴影。五组自有预设包括悬浮软影。CPU 核心按投影射线维护滑动最大值；软化只处理投影图像，支持均匀和随距离增加的柔边。

0.3 渐变模糊根据每个输出位置的投影距离平滑混合不同半径的完整阴影，以避免大半径时产生弧形明暗接缝。固定模糊与 0.2 保持一致。

构建：在根目录运行 `./build.ps1 -Module longshadow`，可加 `-CoreOnly`。参见[构建说明](../docs/BUILDING.md)与[使用说明](../docs/LONGSHADOW_LOCAL.md)。
