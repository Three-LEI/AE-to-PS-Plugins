# JPEG Damage JPEG 损坏 0.1

第十三款 Photoshop 原生滤镜。输入 RGB 像素图层，生成低质量 JPEG 的块状量化、色度损失、振铃以及可重复的局部损坏。菜单：**滤镜 → ZaYu-AE 效果复刻 → JPEG Damage JPEG 损坏**。支持 RGB8/16/32；完整源图上限 16,777,216 像素。使用无需 AE、Sapphire 或 JPEG 编解码运行库。

默认质量为 10%，分辨率系数 1、4:2:0 色度采样，错误率 0。先降低质量获得压缩痕迹；要出现传输错误、块错位和色彩跳变，再提高错误率或直接选择预设。

| 分组 | 参数与用途 |
| --- | --- |
| 压缩 | 质量 1–100%；分辨率系数 1–64；横向比例；4:4:4 / 4:2:2 / 4:2:0 / 黑白；独立色度量化强度 |
| 错误 | 错误率、错误块密度、幅度、聚集度；混合、频率噪声、亮度跳变、块错位、系数丢失、色彩跳变六种模式；块位移及色彩错误强度 |
| 随机 | 随机种子、变化序号、垂直翻转；“换一组损坏”增加变化序号。同参数总是得到相同结果 |
| 频率 | 全部、X/Y、低/中/高频幅度，以及亮度/色度影响比例。DC 均值保留，AC 按频段调节 |
| 颜色与混合 | 高光缩放、暗部偏移、饱和度、混合比例；可保留 HDR 超出 0–1 的原始残差 |
| 蒙版 | 只读 PS 图层输入，亮度×Alpha 或 Alpha；像素单位的模糊及反转。白色作用、黑色保留原图 |

六个内置预设：经典低质 JPEG、重度压缩、传输损坏、块错位、色彩损坏、频率破碎。预设会设置效果参数并清除额外蒙版；随后可逐项修改。参数前的蓝色无边框箭头只恢复该项默认值；底部“全部重置”恢复全部。缩放、背景、语言属于界面状态。保留共用 PS 主题、中英切换、DPI、数值拖动/输入、关于和预览平移缩放。

内核采用面积降采样、YCbCr、真实的可分离 8×8 正交 DCT、T.81 附录 K 示例量化表、系数修改和逆变换。色度单独降低采样率并重建，形成 16 像素色块；部分模式在块读取阶段位移。无损坏的 100% 质量、4:4:4、中性参数及 HDR 保留组合直接返回原图；混合 0 始终直接返回原图。质量和量化曲线为连续的艺术化控制，并非一个输出 JPEG 文件的编码器。横向实际采样间距至少为 1 源像素，避免放大中间缓存。

原始 Alpha 完整保留。HDR 模式在有限范围的 JPEG 基础上加回原 RGB 超范围残差，保持高亮及负值；它是可控的视觉效果，不是 HDR JPEG 编码。蒙版全图对齐后先模糊再混合；PS 选区/羽化由宿主和共用预览路径继续处理。预览异步计算完整分辨率，保留上一张完整结果；源数据、块位置和随机序列与最终输出一致。CPU 按互不重叠的块行并行，宿主取消回调只在调用线程运行，任务结束后才释放输入。

这是根据公开参数语义独立实现的效果。未进行 Sapphire 像素一致性校准，频率控制、损坏序列和 HDR 行为属于本项目的设计。PS 静态图用“变化序号”寻找不同结果；图层蒙版取代外部跟踪蒙版。完整运行器、共用 UI 和原有十二款插件保持 0.27 基线。

构建：`jpeg/build.ps1`；纯内核：`jpeg/build.ps1 -CoreOnly`。需要主工程既有 LLVM-MinGW、Adobe 官方 SDK、Dear ImGui 和 native/build 的共享库。测试包括解析 DC/AC 数学参考、质量损失、种子/模式、蒙版、Alpha/HDR、极端尺寸和取消；实际 DLL 验证 RGB8/PS16/HDR32、原生/旧坐标、分块/选区保护、锁 Alpha、命名蒙版和失败清理。四组生产面板测试包含单项及全部重置。验证状态见 `evidence/jpeg-v01/qa.json`；安装包为整包 0.28。
