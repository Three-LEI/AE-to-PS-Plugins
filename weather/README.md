# Rain & Snow 雨雪模拟 0.2

在「滤镜 → ZaYu-模拟」打开。雨模式生成带风向的雨线，雪模式生成大小不同的雪花。近景粒子较大，远景粒子较细，两层的虚化可分别调整。雨线长宽、雪花大小和虚化都以文档像素计。

- 在照片或智能对象上使用「与原图合成」。
- 在空白像素层上使用「仅粒子」得到透明叠层，可以配合图层蒙版遮住主体。背景层只接收 RGB，单独输出时透明处按黑色显示。
- 点击「雨线颜色」或「雪花颜色」的色块可打开 Photoshop 拾色器。两种颜色独立保存，切换天气时会带回各自的设置。默认雨线为浅蓝色，雪花接近白色。
- 改变「随机种子」可换一种分布。同一文档坐标与种子会重现同一组粒子。模式、种子和其他效果参数随智能滤镜保存。

两种天气直接生成静态画面。滤镜支持 RGB8／16／32，使用 CPU 计算和公共自适应预览。在 100% 及以上缩放时按原尺寸渲染可见区。选区由 Photoshop 控制写回，保留在画布外的内容按文档坐标处理。

效果参考 CC Rainfall 和 CC Snowfall 的公开功能，参数和粒子渲染为本项目独立实现。 [CycoreFX HD 手册](https://www.cycorefx.com/downloads/cfx_hd_std/CycoreFX%20HD%201.8.9%20Manual.pdf#page=103)

从工作区根目录运行 `./build.ps1 -Module weather` 构建。 [参数窗口](../docs/GALLERY.md#rain-snow)
