# Noise 综合杂色 0.2.1（本机）

在「滤镜 → ZaYu-杂色和颗粒 → Noise 综合杂色」打开。基础杂色、胶片颗粒和模拟信号可以独立开启并叠加。默认开启轻微的单色高斯杂色。

| 效果 | 控制 |
| --- | --- |
| 基础杂色 | 平均（均匀）／近似高斯分布、数量、像素尺寸、彩色杂色比例。展开色相、明度和饱和度，可分别控制三项杂色。 |
| 胶片颗粒 | 强度、尺寸、柔和度、粗糙度和彩色比例。粗糙度越高，细碎颗粒越明显。中间调位置控制明暗权重的分界，两侧分别过渡到暗部和亮部的强度。 |
| 模拟信号 | 电视雪花、横向干扰、色度拖尾、局部掉讯。拖尾沿水平方向采样色度，保持当前像素的亮度。掉讯可表现为短白线和短黑线。 |

「效果混合」统一控制三组效果的总强度，0% 返回原图。预设有细微杂色、柔和胶片、粗颗粒胶片、电视雪花、VHS 干扰和胶片与 VHS。随机种子和相位决定固定的噪点分布，随智能滤镜一起保存在 PSD 中。

缩小预览时按像素覆盖面积平均，细颗粒和窄线以缩小后的强度显示。用滚轮或缩放输入框放大到 100% 或以上时，拖动参数会直接计算可见区的原始像素。点击「适合」回到全图视图。RGB8／16／32 使用相同的文档坐标，保留图层 Alpha，选区由 Photoshop 控制写回范围。 [公共交互预览](../docs/ADAPTIVE_PREVIEW.md)

PS2020 21.2.9 实测 RGB8／16／32 的选区、Alpha、撤销、26 个效果字段保存及退出后重开重算。0.1 的三份 PSD 用新版重算，像素与原版一致。PS2026 已安装并核对文件。 [参数窗口](../docs/GALLERY.md#noise)

本机编译运行 `./build.ps1 -Module noise`。单独验证内核可追加 `-CoreOnly`。
